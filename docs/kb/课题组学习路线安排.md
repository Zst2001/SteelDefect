语料身份：学术专科审定原稿（知识库第一篇）。读者是未系统接触深度学习、计算机视觉的研一新生。目标是在共同基础上分叉进入钢铁缺陷检测或钢铁缺陷分割，并按学习进度推荐必读论文。

## 2. 课题组方向一页纸

检索关键词：课题组方向、工业缺陷、钢铁缺陷检测、钢铁缺陷分割、分类检测分割区别。

推荐触发：学生问「我们组做什么」「检测和分割有什么区别」「我该选检测还是分割」。

课题组主线是计算机视觉里的工业表面缺陷检测。本课题聚焦钢铁缺陷语义分割。新生常见细分是两条：钢铁缺陷检测（输出框）、钢铁缺陷分割（输出像素掩码）。两条都要先完成阶段 1–3，再分叉。

不要把三个任务混称「检测」：

| 任务 | 输出 | 标注 | 常用指标 | 本站现状 |
|------|------|------|----------|----------|
| 分类 | 整图一个（或几个）类别 | 图级标签 | Accuracy / F1 | 占位，不可提交真实任务 |
| 检测 | 每个目标一个框 + 类别 | 边界框 | mAP（IoU 阈值下的平均精度） | 占位，不可提交真实任务 |
| 分割 | 每个像素一个类别 | 掩码 | mIoU / Dice | 第一版承诺：内置 baseline 对照与 NEU-20 正式评测 |

工业缺陷相对自然图像的常见难点：小缺陷与大面积缺陷并存；点状、块状、细长裂纹形态异质；低对比、纹理干扰、边界模糊；类别不平衡。不能默认「通用分割/检测网络套过来就够」。

企业产线数据与未授权图像不得进入实验台。网站不做训练、微调或续训；训练在 AutoDL。

## 3. 阶段总览

检索关键词：阶段、学习顺序、分叉、检测路线、分割路线。

推荐触发：学生问「要学多久」「先学什么后学什么」「我该走检测还是分割」。

不按日历周排课。按阶段推进；未达到完成标准不要跳。

```
阶段0 自我诊断
  -> 阶段1 Python 与数学直觉
  -> 阶段2 深度学习入门
  -> 阶段3 CV 与分类骨干
  -> 分叉
       检测（框 / mAP / YOLO）-> 阶段4A -> 阶段5A 钢铁缺陷检测入门
       分割（掩码 / mIoU / U-Net）-> 阶段4B -> 阶段5B 钢铁缺陷分割入门 -> 本站实验台
```

Transformer 不是 NLP 专属：阶段 3 读 Attention 与 ViT；检测分叉接到 DETR；分割分叉接到 SegFormer。

## 4. 阶段 0 自我诊断

检索关键词：诊断、基础如何、会不会 Python、框还是掩码、我适合哪个方向。

推荐触发：学生说「零基础」「没学过深度学习」「不知道自己该读什么」；或助手尚未知道其进度。

按顺序问，根据回答停在对应阶段，不要一次问完就推论文。

1. 能否独立写出读取图片、把像素变成数组、做简单循环的 Python 脚本？不能 → 停在阶段 1。
2. 能否用一句话说清：模型预测、损失函数、用梯度更新参数、过拟合是什么？不能 → 停在阶段 2。
3. 能否解释卷积在做什么，以及分类网络输出的是类别而不是框或掩码？不能 → 停在阶段 3。
4. 目标是框出缺陷，还是画出缺陷像素范围？框 → 阶段 4A；像素/掩码 → 阶段 4B；还没定 → 先用第 2 节任务对照表讲清差异，再让学生选。
5. 是否已经知道工业缺陷相对自然图像的难点（尺度、形态、低对比、不平衡）？否 → 在 4A/4B 之后进入阶段 5，不要跳过任务基础直接读钢铁论文。

学生只说「想做钢铁缺陷」时，先完成问题 4，再推荐 4A 或 4B 的论文卡。

## 5. 阶段 1 Python 与数学直觉

检索关键词：Python、NumPy、零基础编程、线性代数、矩阵。

推荐触发：学生说「不会编程」「Python 不熟」「数学会不会不够」。

目标：能把一张图读成数组，做切片、均值、归一化，而不是先啃证明。

建议材料类型（不指定未核验的第三方博客）：Python 官方 Tutorial 的基础语法；NumPy 官方「quickstart」；线性代数只需矩阵乘、转置、范数的直觉。不把数学课当关卡。

完成标准：自己写脚本读取一张图像，打印形状，做缩放或裁剪，保存结果。说得出「一张灰度图是 H×W 的数组，彩色图常是 H×W×C」。

常见弯路：先去背高等数学全书；在没写过加载图像的代码前就读论文。

本阶段不推荐论文。

## 6. 阶段 2 深度学习入门

检索关键词：深度学习入门、损失、反向传播、过拟合、PyTorch、怎么训练。

推荐触发：学生问「深度学习是什么」「什么是损失」「如何开始用 PyTorch」。

目标：建立一个最小训练闭环：数据 → 模型 → 损失 → 反向传播 → 更新参数 → 看训练/验证曲线。

建议材料类型：PyTorch 官方 Tutorials 中的入门训练示例（如 60-minute blitz、训练分类器）；用一个小分类问题跑通，不必一开始就上缺陷数据。

必须建立的概念：监督学习；损失不是准确率；梯度下降；过拟合与验证集；batch、epoch、学习率。

完成标准：能用自己的话解释「为什么训练损失下降但验证变差可能是过拟合」；能改一个官方示例的超参数并描述曲线变化。还不能把 Accuracy 和 loss 当成同一个数。

常见弯路：没跑通任何训练就直接复现顶会仓库；把测试集拿来调参。

本阶段不推荐论文。问 CNN/ResNet/Transformer 时，告诉学生先完成阶段 2，再进入阶段 3。

---

## 7. 阶段 3 计算机视觉与分类骨干

检索关键词：计算机视觉入门、卷积、CNN、ResNet、分类、ImageNet、骨干网络。

推荐触发：学生问「CV 怎么入门」「什么是卷积」「什么是骨干 backbone」「为什么都用 ResNet」。

目标：理解图像如何变成张量、卷积如何提取局部纹理、分类任务输出什么；读通 ResNet，建立「骨干网络」概念。随后按需读 Transformer 与 ViT，为后面的检测 DETR、分割 SegFormer 做桥。

建议材料类型：PyTorch 官方图像分类示例；概念课类型可选斯坦福 CS231n（课程名可核，本语料不锁定某一镜像 URL）。

完成标准：能区分分类 / 检测 / 分割的输出；能说出残差连接要解决什么；能指出骨干（抽特征）和任务头（分类/检测/分割）不是一回事。

本阶段必读论文卡：ResNet。若学生主动问注意力或 Transformer，再读 Attention Is All You Need，然后 ViT。不要在阶段 3 同时塞检测和分割论文。

常见弯路：把 ResNet 论文里的 ImageNet 数字抄进钢铁缺陷报告；把骨干论文当成自己的方法贡献。

## 8. 阶段 4A 目标检测分叉

检索关键词：目标检测入门、边界框、IoU、NMS、mAP、YOLO、Faster R-CNN、单阶段双阶段。

推荐触发：学生说「我做检测」「要画框」「YOLO」「mAP」「缺陷定位用框」。

前置：阶段 1–3 完成。未完成时先回去，不要从 YOLO 仓库起步。

本阶段概念：边界框；IoU（交并比）；NMS（非极大值抑制，用来去掉重叠重复框）；mAP（在一组 IoU 阈值下看检测精度，具体协议以所用数据集论文为准，不要把本站演示数字写成 mAP）。双阶段（先提议区域再分类回归，代表 Faster R-CNN）与单阶段（直接在图上预测框，代表 YOLO）是两条主范式。DETR 把 Transformer 接到检测，去掉手工锚框与 NMS 是其宣传点，入门时先建立 YOLO / Faster R-CNN 对照，再读 DETR。

完成标准：能用自己的话对比 YOLO 与 Faster R-CNN；能解释 IoU 与 NMS 各自解决什么；知道 mAP 不是分割的 mIoU。

本阶段必读论文卡：YOLO v1，YOLOv3，Faster R-CNN。问「检测遇到 Transformer」时再读 DETR。

本站实验台当前不承诺目标检测真实任务。阶段 4A 是学术入门，不是「本站可以跑检测」。跑实验请走分割与 AutoDL。

## 9. 阶段 4B 语义分割分叉

检索关键词：语义分割入门、掩码、像素级、mIoU、Dice、U-Net、DeepLab、跳跃连接、编码器解码器。

推荐触发：学生说「我做分割」「要像素级别」「掩码」「U-Net」「mIoU」「缺陷范围」。

前置：阶段 1–3 完成。

本阶段概念：每个像素一个类别；编码器下采样抽语义、解码器上采样恢复空间；U-Net 的跳跃连接把浅层细节接到解码器，这对小缺陷和边界很关键。DeepLabv3+ 用空洞卷积与编码器–解码器加强多尺度上下文。本站内置 baseline 是 UNet / DeepLabV3+ / UNet++，所以 UNet++ 也在必读之列。分割侧的 Transformer 代表读 SegFormer，不要以为只有检测才用 Transformer。

常用指标：mIoU（各类 IoU 再平均）；Dice。没有配对 GT（真值掩码）时，本站不得口述精度。

完成标准：能画「编码–解码 + 跳跃连接」的示意图（口头或纸面即可）；能区分 mIoU 与检测 mAP；能说明为什么工业小缺陷特别依赖浅层细节。

本阶段必读论文卡：FCN，U-Net，DeepLabv3+，UNet++。问 Transformer 分割时再读 SegFormer。

## 10. 阶段 5A 钢铁缺陷检测入门

检索关键词：钢铁缺陷检测、NEU-DET、热轧钢板、工业表面缺陷检测。

推荐触发：学生已完成 4A，或问「钢铁缺陷检测读什么」「NEU-DET 是什么」。

前置：阶段 4A。未学框、IoU、mAP 时不要直接读钢铁检测论文。

入门目标：知道公开集从何而来、缺陷类别大致是什么、工业图与自然图差在哪。不是做领域综述，也不是复现全部 SOTA。

必读：Song 与 Yan 2013 的 NEU 表面缺陷分类数据工作（理解热轧钢板缺陷图从哪来）；He 等人 2020 的 NEU-DET 检测工作（理解框标注与检测设定）；Liu 等人 2023 综述（只建脉络，不作原创证据）。

锁死口径：本站 NEU-20 只有 20 张，是预置固定测试集，不是官方 test split，不是完整 NEU-DET 评测，不得写进论文当正式测试集。

## 11. 阶段 5B 钢铁缺陷分割入门

检索关键词：钢铁缺陷分割、NEU-Seg、磁瓦 Magnetic Tile、BSData、像素级缺陷、弱缺陷、细长裂纹。

推荐触发：学生已完成 4B，或问「钢铁分割读什么」「工业缺陷分割难点」。

前置：阶段 4B。

入门目标：把通用分割网络的适用边界讲清楚。任务特点（与组内汇报口径一致，此处不把在研方法当成已发表成果）：尺度上小目标与大面积并存；形态上点状、块状、细长、不规则同时出现；外观上低对比、纹理干扰、边界模糊；分布上类别不平衡。因此「只换一个更强的 ImageNet 骨干」通常不够。

公开集入门点名（任务类型，不编造未核验 DOI）：

- NEU 系图像源自 Song 与 Yan 2013；检测框设定见 He 等人 2020（NEU-DET）。组内汇报使用的 NEU-Seg 是像素级设定（热轧钢板，含夹杂、斑块、划痕及混合缺陷）。本语料未核到题名为 NEU-Seg 的独立 DOI，不得编造数据集论文。引用数据来源时用已核验的 Song 2013 / He 2020，并写明自己用的是分割掩码还是检测框。
- Magnetic Tile（磁瓦表面缺陷显著性）：Huang、Qiu、Yuan，2018，The Visual Computer，DOI `10.1007/s00371-018-1588-5`（已核验）。类别不平衡、含正常样本。
- BSData（钢表面点蚀分割，组内汇报口径为点蚀、缺陷小而散、对比度低）：本语料未从 Crossref / OpenAlex 核到独立数据集论文 DOI，不得编造。可作「公开点蚀分割数据」提及，引用时标「数据集论文 DOI 未收录」。

必读论文卡：He 等人 2020（了解钢铁缺陷从分类走到检测的问题设定，分割新生也要知道框和掩码不是同一标注）；Huang 等人 2018；Liu 等人 2023 综述。分割方法主干仍用阶段 4B 的 U-Net / DeepLabv3+ / UNet++。

锁死口径：本站正式评测只用 NEU-20（20 张），不是论文完整测试集。公开演示即使样例带 GT 也不展示、不口述 mIoU / mDice / Acc。

## 12. 必读论文卡

使用规则：每张卡可单独检索。推荐时必须同时满足「前置阶段」和「推荐触发」。DOI / arXiv 均为 2026-10-14 核验；核不到的标识已在卡内写明，禁止补写假 DOI。

### 12.1 ResNet（残差网络）

检索关键词：ResNet、残差、backbone、He Kaiming、CVPR 2016、分类骨干。

短名：ResNet  
文献：He, Zhang, Ren, Sun. Deep Residual Learning for Image Recognition.  
年份 / venue：2016 / IEEE CVPR  
DOI：`10.1109/cvpr.2016.90`（Crossref 已核验）  
一句话贡献：用残差连接训练很深的卷积网络，让骨干可以明显加深而不那么容易退化。  
对本组为什么重要：后续检测、分割几乎都从「先有一个骨干」出发；工业缺陷论文里常见 ResNet 作编码器。  
前置阶段：阶段 2 完成。  
推荐触发：学生问 CNN、卷积网络、骨干、ResNet、为什么网络可以很深。  
读后应能回答：残差块输入输出如何相加；为什么这比纯堆卷积更容易优化；骨干和任务头的分工。  
不必精读：ImageNet 全部消融表、每层通道数的逐项抄录。不要把文中 ImageNet 精度写进钢铁缺陷实验。

### 12.2 Attention Is All You Need（Transformer）

检索关键词：Transformer、自注意力、Attention Is All You Need、Vaswani、注意力机制。

短名：Transformer  
文献：Vaswani, Shazeer, Parmar, Uszkoreit 等. Attention Is All You Need.  
年份 / 标识：2017，arXiv:`1706.03762`（arXiv API 2017-06-12 已核验）。文献中常记为 NeurIPS 2017；本语料未从 Crossref 核到独立 DOI，引用与检索用 arXiv 号。  
一句话贡献：提出以自注意力为主的序列模型，不再把循环网络当作默认骨干。  
对本组为什么重要：ViT、DETR、SegFormer 都从这里的注意力思想来；新生必须知道 Transformer 先出现在序列建模，再进入视觉。  
前置阶段：阶段 2 完成；最好已建立「网络=可学习函数」的直觉。可与 ResNet 并行，但不要跳过阶段 2。  
推荐触发：学生问 Transformer、注意力、self-attention、「检测/分割里的 Transformer 从哪来」。  
读后应能回答：Query / Key / Value 在做什么；自注意力与卷积在「感受野」上的差别；为什么计算量随序列长度变贵。  
不必精读：机器翻译实验的全部 BLEU 表。不要声称自己已经「提出了 Transformer」。

### 12.3 ViT（Vision Transformer）

检索关键词：ViT、Vision Transformer、图像块 patch、Dosovitskiy、ICLR 2021。

短名：ViT  
文献：Dosovitskiy, Beyer, Kolesnikov 等. An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale.  
年份 / venue：预印本 2020（arXiv:`2010.11929`，arXiv API 已核验）；OpenAlex 另有 2021 ICLR 会议条目（无 Crossref DOI）。入门引用用 arXiv 号，venue 可写 ICLR 2021。  
一句话贡献：把图像切成块（patch）再送进 Transformer，证明纯注意力也可以做图像识别。  
对本组为什么重要：是「Transformer 进入 CV」的分类侧桥；读完再去看 DETR（检测）或 SegFormer（分割）才不会觉得突然。  
前置阶段：阶段 3；须先读懂 12.2，否则不要从 ViT 起。  
推荐触发：学生问 ViT、图像怎么喂给 Transformer、patch embedding。  
读后应能回答：一张图如何变成 token 序列；为什么数据规模对 ViT 很关键；它与 ResNet 抽特征方式的差别。  
不必精读：全部缩放实验与 JFT 数据细节。工业小数据上不要默认「上 ViT 一定更强」。

### 12.4 FCN（全卷积分割）

年份 / venue：2015 / IEEE CVPR

### 12.5 U-Net

检索关键词：U-Net、UNet、跳跃连接、编码器解码器、医学分割、Ronneberger、MICCAI。

短名：U-Net  
文献：Ronneberger, Fischer, Brox. U-Net: Convolutional Networks for Biomedical Image Segmentation.  
年份 / venue：2015 / MICCAI（Crossref 容器名为 Lecture Notes in Computer Science）  
DOI：`10.1007/978-3-319-24574-4_28`（Crossref 已核验）  
一句话贡献：对称的编码–解码结构，并用跳跃连接把浅层细节送到解码器，适合小样本、需要精细边界的分割。  
对本组为什么重要：工业缺陷小、边界弱，和医学小样本分割的需求相近；本站内置 baseline 含 UNet。钢铁分割新生的第一篇方法论文就是它。  
前置阶段：阶段 4B；建议先扫过 FCN，再精读 U-Net。  
推荐触发：学生问 U-Net、UNet、跳跃连接 skip connection、分割入门读什么、小缺陷怎么保细节。  
读后应能回答：U 形结构左右如何对应；跳跃连接拼接的是什么；为什么这对小目标和边界有用。  
不必精读：细胞跟踪比赛的全部排表。不要把生物医学数据上的数字直接写成钢铁缺陷 SOTA。

### 12.7 UNet++

检索关键词：UNet++、UNetPP、嵌套跳跃、nested skip、本站 baseline、Zhou Zongwei。

短名：UNet++  
文献：Zhou, Rahman Siddiquee, Tajbakhsh, Liang. UNet++: A Nested U-Net Architecture for Medical Image Segmentation.  
年份 / venue：2018 / DLMIA–MICCAI 研讨（Crossref 容器名为 Lecture Notes in Computer Science）  
DOI：`10.1007/978-3-030-00889-5_1`（Crossref 已核验）  
期刊扩展：Zhou 等. UNet++: Redesigning Skip Connections to Exploit Multiscale Features in Image Segmentation. IEEE TMI，2020。DOI `10.1109/TMI.2019.2959609`（Crossref 已核验）。入门先读 2018，需要更完整实验再读 TMI。

### 12.8 SegFormer（分割侧 Transformer）

检索关键词：SegFormer、Transformer 分割、SegFormer Xie、层次化 Transformer。

短名：SegFormer  
文献：Xie, Wang, Yu, Anandkumar 等. SegFormer: Simple and Efficient Design for Semantic Segmentation with Transformers.  
年份 / 标识：2021，arXiv:`2105.15203`（arXiv API 2021-05-31 已核验）。文献中常记为 NeurIPS 2021；本语料未从 Crossref 核到会议 DOI，引用用 arXiv 号。  
一句话贡献：用层次化 Transformer 编码器加轻量解码器做语义分割，避免再套一个沉重的解码 Transformer。  
对本组为什么重要：证明 Transformer 可以走分割，而不是只存在于分类 ViT 或检测 DETR。工业长裂纹需要更大范围上下文时，用它理解「全局建模」这条线。

推荐触发：学生问分割方向的 Transformer、SegFormer、「除了 U-Net 还有没有注意力分割」。  
读后应能回答：层次化 encoder 相对 ViT 单尺度 patch 的差别；它为什么可以不用复杂解码器。  
不必精读：全部公开榜数字。不要把 ADE20K 结果写成钢铁缺陷结果。

### 12.9 Faster R-CNN

检索关键词：Faster R-CNN、RPN、区域提议、双阶段检测、Ren Shaoqing、锚框。

短名：Faster R-CNN

DOI：`10.1109/tpami.2016.2577031`（Crossref 已核验）。会议版常见引用为 NeurIPS 2015；本语料以已核验的 TPAMI DOI 为准。  
一句话贡献：用区域提议网络（RPN）把「提框」和「识别」合成近乎实时的双阶段检测器。  
对本组为什么重要：是理解锚框、RPN、双阶段检测的标准参照；和 YOLO 对照着读，才知道单阶段在简化什么。

### 12.10 YOLO v1（单阶段检测范式）

检索关键词：YOLO、YOLOv1、You Only Look Once、单阶段、Redmon、实时检测。

短名：YOLO v1

一句话贡献：把检测变成一次前向的回归问题，整图预测框和类别，强调速度与统一建模。  
对本组为什么重要：工业质检常提实时；新生必须从这一篇理解「单阶段」四个字，而不是从某个工程仓库的 README 开始。  
前置阶段：阶段 4A。

### 12.11 YOLOv3（YOLO 族可读后续）

检索关键词：YOLOv3、多尺度检测、Redmon Farhadi、YOLO 系列。

短名：YOLOv3

年份 / 标识：2018，arXiv:`1804.02767`（arXiv API 2018-04-08 已核验；OpenAlex 记为预印本）。这是技术报告式增量改进，不是顶会长文，入门仍值得读，因为多尺度预测写得直白。  
一句话贡献：在 YOLO 族上加入多尺度预测等工程与结构改进，使不同大小目标更好处理。  
对本组为什么重要：钢铁缺陷尺度差异大；读完 v1 再读 v3，能看到「单阶段如何补小目标」。  
前置阶段：已读 YOLO v1。

### 12.12 DETR（检测侧 Transformer）

一句话贡献：用 Transformer 做端到端集合预测检测，把框的匹配当成集合匹配问题。  
对本组为什么重要：这是「检测遇到 Transformer」的桥；学生问完 YOLO 再问 Transformer 检测时读它，避免误以为 YOLO 就是检测的终点。

检索关键词：实验台、NEU-20、内置模型、UNet DeepLabV3+ UNet++、导入、catalog、公开演示、FPS、模型适配助手。

推荐触发：学生问「网站怎么用」「如何对照」「NEU-20 是什么」「能不能跑 YOLO」「首页论文能不能跑」。

学术入门完成阶段 4B 后，分割方向才适合上本站做对照。检测方向目前只能在 AutoDL 等站外环境做，本站检测管道未就绪，不得用分割工具冒充检测。

建议操作顺序（这是实验台路线，不是论文路线）：先分清对比 / 评测 / 公开演示；在缺陷分割页用内置 UNet / DeepLabV3+ / UNet++ 对照自己的图；导入单个 `.py` 与 `.pth`，检查通过后再加入对照；需要全量指标时用正式评测（仅 NEU-20）。

必须遵守：

- NEU-20 只有 20 张，不是论文完整 test split，不是官方测试集，不是完整 NEU-DET 评测。
- 公开演示即使样例带 GT 也不展示、不口述 mIoU / mDice / Acc。
- 快速对比在全部配对掩码后给出的是本批参考指标，不代表完整测试集性能。
- 本机 FPS = 1000 / ms/图，协议是 CPU、batch=1、dummy 随机输入，不是 CUDA 论文测速，也不是测试集指标。
- 首页 catalog 文献卡片不是可运行模型，不要把论文名当成 `version_id`。可运行版本只在模型中心：内置 baseline 与检查通过的学生版本。
- 网站不做训练。训练、微调、续训在 AutoDL。
- 导入失败到该版本模型卡使用模型适配助手，不要让科研助手改源码。科研助手学术专科不能调度分割入队或测速。
- 企业产线数据与未授权图像不得进入实验台。
- 第三方仓库、论文 GitHub、未审定网页不是本组成果，禁止写成已在本站落地。
