# PCB 分割工作台四模块布局调整与验证

日期：2026-11-03。结果：**PASS**。

## 本次修改

本轮产品代码仅调整 `apps/web/src/views/pcb/PcbNewView.vue` 的模板和页面局部样式，保留先前尚未提交的功能实现。

桌面改为同一个 CSS Grid 中的四个直接子模块：

| 左列 | 右列 |
|---|---|
| 上传 PCB 原图 | 选择分割模型 |
| 附加分析选项 | 提交摘要 |

- 两列等宽，同行顶部和底部对齐；附加分析位于上传正下方，提交摘要位于模型选择正下方。
- 四个模块标题统一改为深青色 `#216d67`，与主标题及蓝色操作按钮区分。
- 主标题右侧添加“上传原图 → 选择模型 → 查看对比”，下方仅补充“GT 标签与 Grad-CAM 按需开启”。删除原句“选择多张图像与分割模型，在原始像素坐标下比较缺陷区域。”
- 压缩上传空白区域；多图列表和 GT 映射列表有最大高度及内部滚动，控制页面纵向膨胀。提交按钮位于摘要下部。
- 宽度不超过1000px时改为单列，顺序为上传、模型、附加分析、提交摘要；操作流程移至标题下方。

未修改本页脚本中的上传、配对、模型选择、预算、提交、幂等或权限逻辑；未修改后端、模型、`.env`，没有提交或推送 Git。沿用现有浅色风格，没有改全局主题、首页或 PCB 分类页面。

## 验证结果

证据目录：`docs/report/pcb-layout-20261103/`。最终结果使用其中 `final-browser/` 和 `final-build/`，早期检查结果保留。

| 检查 | 结果 |
|---|---|
| 现有 PCB 批次交互 mock | 48项通过，包含整区上传、键盘、多图追加/拖拽、模型选择、GT/CAM、幂等重试及响应式行为 |
| 1920px 桌面 | 四模块各宽802px，两行分别顶底对齐，无横向溢出 |
| 1440px 桌面 | 四模块各宽562px，两行分别顶底对齐，无横向溢出 |
| 1024px 窄桌面 | 四模块各宽354px，两行分别顶底对齐，无横向溢出 |
| 768px / 390px | 单列顺序正确，各模块分别宽736px / 358px，无横向溢出 |
| Vite生产构建 | 通过；PCB分割及分类页面正常打包 |
| Preview私有资源访问 | PCB分割320次、PCB分类320次GET/HEAD拒绝检查通过 |

浏览器使用临时随机回环端口、mock API、现有 Playwright，不连接日常 API/数据库或模型服务；未重跑CPU推理。`layout-check.mjs` 是现有交互验收脚本加入尺寸记录和截图后的证据副本，没有改动正式测试套件。原有完整类型检查工具未安装，本轮不声称运行 vue-tsc；构建仍有既有的大 chunk 提示。

已查看空表单、多图/GT/CAM选择后的桌面截图及移动端截图；浏览器尺寸数据确认四卡片等宽和每行对齐。
