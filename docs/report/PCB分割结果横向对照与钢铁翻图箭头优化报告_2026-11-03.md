# PCB 分割结果横向对照与钢铁翻图箭头优化报告

日期：2026-11-03

## 1. 本次目标与完成情况

已将 PCB 批次结果页从“逐图折叠任务列表”改为直接显示的横向对照界面，并加深钢铁分割结果页的翻图箭头。沿用现有任务、授权文件接口和结果文件，不改变推理、GT 配对或指标计算逻辑。

本次未修改后端、模型资产、`.env`、首页或侧栏，未训练、提交 Git 或推送。工作区此前已有多项未提交修改，本报告仅描述本次结果界面调整。

## 2. PCB 结果界面

入口：现有 PCB 批次结果路由，对应 `apps/web/src/views/pcb/PcbBatchView.vue`。

- 默认直接显示“原图 → GT → 各模型分割结果”，无需逐项展开；三模型任务通常为五列。
- 左上角提供掩码拼图、叠加拼图、概率热力图、Grad-CAM、边界拼图、错误图拼图六个视图。
- 右上角提供图片选择、序号和上一张/下一张按钮；切图时同步更新全部模型结果及本张图片指标。
- 原图和 GT 始终保留在前两列；没有 GT 时显示说明，不用预测掩码替代 GT。
- GT 的原始 0/1 数据仅在浏览器中增强显示；下载仍使用既有原尺寸文件。
- 点击图片可放大；保留图层下载、原始 0/1 掩码下载和独立任务详情入口。
- 只加载当前图片的所选图层；窄屏在对比区内横向滚动，不撑开整个页面。
- 失败、排队、运行中和未提供图层均有明确占位。失败任务可独立重跑，成功结果仍可查看。
- 重跑任务保留独立列与任务编号，不覆盖原任务；模型数或重跑次数较多时允许横向滚动。

这里的“拼图”由页面并排展示现有授权图层实现，没有生成额外服务端拼图文件，也没有重新执行推理。

## 3. 数据与交互边界

- 无 GT 时不显示数值指标表，并禁用错误图；从有 GT 的错误图切换到无 GT 图片时自动回到掩码视图。
- 指标来自当前图片的各任务返回值，只有任务成功、存在 GT 且指标可用时才显示；未完成或无定义值显示“—”。
- 概率热力图与 Grad-CAM 分开呈现。未请求或不支持 CAM 时显示原因，不用概率图冒充 CAM。
- 按任务分页读取现有批次接口，跨页按图片合并、按任务 ID 去重，避免重跑较多时遗漏模型列。
- 轮询保留当前样本 ID；路由切换与卸载使用请求取消及版本标记，防止旧响应覆盖新批次。
- 批次读取失败或授权撤回后隐藏旧结果；单张图层加载失败可单独恢复。
- 下载与重跑的异步反馈使用独立标记保护，避免旧路由操作污染新页面状态。已主动发起的下载不会因切换路由而被强制取消。
