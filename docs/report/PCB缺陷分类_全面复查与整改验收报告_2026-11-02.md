## 3. 发现的问题及整改

| 问题 | 具体影响 | 本轮处理与代码位置 | 验证 |
| --- | --- | --- | --- |
| 源码身份直到首次准入调用才绑定 | 常驻进程载入旧代码后，磁盘代码和回执在首次请求前更新，可能错误认可新版本身份 | `packages/infer/pcb_classification/catalog.py:97` 在模块导入时固定源码与运行环境身份；后续变化拒绝准入 | 首次调用前代码变更、匹配新回执仍拒绝；运行环境变更必须重启 |
| 运行身份只取安装元数据不能完全代表已载入库 | Worker 可能先加载 torch，再懒加载 PCB 模块；就地更新依赖可产生旧库、新 metadata | `packages/infer/pcb_classification/runtime.py:71` 在推理入口核对实际 torch/torchvision/NumPy/Pillow 版本与回执 | 模拟已载入 torch 版本不同，确认不加载模型并清空缓存 |
| 返回可变配置缓存引用 | 调用方改动返回的类别或归一化参数，可污染后续缓存读取 | `catalog.py::verify_release` 返回深拷贝；配置解析纳入最终文件身份复验 | 修改返回值不影响后续配置；解析期间文件变更拒绝进入缓存 |
| 回执结构和 PASS 字段校验不足 | null/list/畸形模型条目可能导致目录 500；非空字符串也可当作 passed | `catalog.py::admitted` 校验根对象、模型对象、严格布尔值、权重 SHA、严格加载、键数量及参数量 | 18 类结构/字段反例均拒绝；目录正常返回不可用 |
| 准入脚本依赖 assert，而优化解释器会移除断言 | 使用 `-O`/`-OO` 时可能跳过重要准入判定 | `scripts/admit_pcb_classification_cpu.py:48` 在入口拒绝优化解释器 | 两种优化模式均在加载模型、写报告/回执前退出 |
| 推理后的准入复验抛错时未立即释放常驻模型 | 虽不会发布本次结果，但内存仍保留已失效缓存，直到下一请求处理 | `runtime.py::predict` 统一异常清空缓存，再恢复线程设置 | 后验抛错与 token 改变两个用例均清空模型缓存 |
| 不确定提交后切换模型 A→B→A 丢失 A 的幂等键 | 重试可能新建一个本已提交的任务 | `PcbClassifyNewView.vue:47` 按批次与模型保留页面生命周期内的请求键 | A/B 键不同，回到 A 复用原键，只上传一次；清图后重置 |
| 展示和下载对结果身份校验不足 | 数值合法但任务、模型、协议或标签错误的 JSON 仍可能展示/保存 | `classification-types.ts:13::checkedRoiResult` 统一校验；结果页展示和下载共同使用 | 错任务、模型、协议、中文标签、argmax、畸形类别和下载反例均拒绝 |

导入时冻结运行身份的实现同时保留了轻量 API 的降级能力：缺少可选 ML distribution 时仍可导入目录模块，模型显示不可用；在当前进程内临时安装依赖不会自动恢复准入，须重启。API 没有为了此检查而导入 torch。

## 6. 真实业务链路与权限验收

入口和职责未改变：

`/inspect/pcb/classification → POST uploads → POST tasks → MySQL Task/冻结输入 → Redis/RQ → apps.worker.jobs.run_pcb_classification → apps.worker.pcb_classification.run_body → infer.pcb_classification.runtime.predict → Artifact/终态/审计 → GET tasks/文件下载`

关键代码：

- `apps/api/app/services/pcb_classification.py::create_batch/create_task/snapshot/serialize_task`：校验、私有批次、固定模型、幂等提交、冻结输入及序列化。
- `apps/api/app/services/input_freeze.py`：样本内容和分类协议身份复核。
- `apps/worker/pcb_classification.py::assert_execution/run_body`：执行前、发布前复核；暂存后发布两项结果；异常处理。
- `apps/api/app/services/tasks.py` 与 `task_artifacts.py`：任务可见性与 Artifact 白名单。
- `apps/api/app/services/pcb_delivery.py`：领取前失败补偿，限制队列函数、任务类型与作业身份。

| 链路 | 本轮证据 |
| --- | --- |
| 两模型上传→排队→推理→结果→下载 | 3 个浏览器任务成功：EfficientNet 原生 PNG、MobileNet RGB JPEG 转换、MobileNet 原生 PNG；后一个验证常驻缓存命中 |

| 私有资产外露 | 真实 API/Vite 和生产预览的路径编码、变体等拒绝探测通过；构建产物递归扫描未包含私有权重/资产 |
