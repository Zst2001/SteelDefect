# 公开提交的验收证据范围

本目录随 PCB 集成提交同步了测试结果、权限探测结果及选定截图。完整验收结论见上一级《PCB缺陷分类_全面复查与整改验收报告_2026-11-02.md》。

原始资产、模型权重、私有准入回执、含内部参考 logits 的完整 CPU 准入 JSON、原始运行日志、Git 工作区快照及其余截图仅保存在验收机器本地，没有随本次提交公开。报告中指向这些本地证据的链接，在 GitHub 上可能不可用；不能以缺失链接推断已重新验证或自动获得部署准入。

部署机器仍需自行安装经核验的私有资产、运行 CPU 准入并重启 API/Worker。PCB 分割与分类的配置默认关闭，本次提交不携带日常环境配置。

提交检查发现的 Markdown 双空格换行和既有模型文件末尾空行仅属格式提示；为保持已经验收的源码身份，本次推送准备没有格式化推理文件。
