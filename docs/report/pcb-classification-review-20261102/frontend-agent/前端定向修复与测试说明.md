# PCB 分类前端定向修复与测试说明

日期：2026-11-02。范围：PCB 单缺陷 ROI 分类工作台、结果页及其任务页签；不涉及首页、侧栏、后端、模型权重或实验指标。

## 审查结论与修复

| 问题 | 原实现证据 | 本次处理 | 验证 |
| --- | --- | --- | --- |
| 不确定提交后切换模型 A → B → A，原请求键丢失 | `PcbClassifyNewView.vue` 原 `watch(selected)` 清空唯一 `idempotencyKey` | 按当前上传批次与模型保存请求键；同一组合重试复用，换图或移除后清理 | 两模型请求键不同，回到 A 复用 A 的请求键；整个过程只上传一次 |
| 结果可在六类数值合理时混入其他任务或模型的数据 | `PcbClassifyTaskView.vue` 原 `result` 仅核对数量、数值范围、总和和英文类别 | `classification-types.ts::checkedRoiResult` 统一校验协议、任务与模型身份、两种标签、概率 argmax、输入 SHA-256 格式等；畸形 classes 不再触发脚本异常 | 任务、模型、协议、中文标签、argmax 与 classes 畸形六组反例全部拒绝展示 |
| 单独下载的 JSON 未复核内容 | 原 `download` 校验 URL 后直接保存返回体 | 下载返回体复用结果契约检查，不合规时显示错误且不保存 | 错任务 JSON 下载被拒绝，正确 JSON 正常保存 |
| 无效结果提示要求重载，但没有操作入口 | 原成功但无效结果分支只有文字 | 增加“重新加载结果”按钮 | 服务端随后返回有效结果时，可恢复显示六条概率 |
| 很小的非零概率显示为 `0.00%`，接近一显示为 `100.00%` | 原百分比统一 `toFixed(2)` | 小于 0.01% 且非零显示 `<0.01%`；大于 99.99% 且小于一显示 `>99.99%`；meter 提供同样的可访问文本 | 文本与可访问属性均核验 |
| ROI 无法直接移除 | 原仅有选择/更换按钮 | 增加移除按钮，撤销预览 URL、清理错误和批次，并使未完成的解码结果失效 | 移除后不能提交，重新选择生成新批次和请求键 |

同时核对接口外层任务 ID、协议和状态枚举，避免错误任务或未知状态静默显示；为 PCB 页签补充 `aria-current`。保留已有按路由代次丢弃迟到响应的实现，并补测其行为。
