## 1. 可用功能与使用入口

登录后进入「缺陷检测 → 钢铁检测 → 缺陷分类」，路径 `/inspect/steel/classification`。

1. 选择 1–50 张 PNG/JPEG/BMP/TIFF 原图，单张不超过 10 MiB、400 万像素、长宽比不超过 4:1；仅支持单帧及明确支持的图像模式。拒绝损坏图像和重复字节内容。
2. 默认选择 MobileNetV3-Small，可选其他通过校验的模型，单任务 1–3 个。目录状态依据本地资产、指纹、运行时和 CPU 复验凭据，不使用静态假状态。
3. 可不提供标签，或为全部图片填写 0–5 的真实标签。部分标签、非法标签和布尔值标签会被拒绝；不会自动用预测作为真值。
4. 提交后查看排队、执行、成功、部分成功或失败状态；完成后显示原图、各模型 Top-1 与 Top-3 得分，并可下载授权的分类 JSON。
5. 完整 GT 批次才产生 Accuracy、Macro-F1、6×6 混淆矩阵。无 GT 的 API 只返回 `metrics: {available:false}`，数据库不创建该任务的 MetricSet。Macro-F1 固定在六类上平均，零分母按 0，单类小批次的数值因此不等同于“只平均本批出现的类”。
6. 历史记录支持分类筛选、打开结果，以及沿用权限允许的备注、归档、提交导师、撤回与重跑；分类任务不会开启分割科研分析工具或分割 ZIP 下载。

默认模型损坏时，其他已验证模型仍可选择和运行；全部不可用时阻止提交。分类批次通过任务查看，不在分割数据集目录中显示成空数据集。

前端保持现有蓝白浅色工作区、场景顶部切换和侧栏结构。新分类结果页也归属于钢铁检测导航。桌面与 768/390 px 布局已检查；截图是明确标注的模拟业务数据，不是模型精度证据。

### 3.1 Schema 与存储

无需 Alembic 或生产迁移。已有 `Task.type` 是 String(16)，能容纳 `classification`；本轮 `db/models.py` 仅更新注释。

- `DatasetVersion.kind=classification_batch`，`class_map_json` 保存 task_kind、classes、protocol_hash、labels_by_sample_key、filenames。图级标签从不写入 `mask_uri`。
- `PreprocessSpecRow.dataset=neu_cls`，JSON 保存真实 classes/preprocess；宽高 224 是登记元数据，运行以导出整数 Resize 协议为准。
- 可信 Model/ModelVersion/Weight 按权重与协议确定性登记；登记冲突通过 savepoint 与当前读处理，不静默覆盖旧记录。登记发生在用户操作时，本轮没写生产表。
- 原字节图片存于配置的 storage 根下 `classification/{batch_id}/`，文件名由系统生成，原始文件名仅用于显示。
- 冻结文件为 `tasks/{task_id}/inputs.json`；结果原图 PNG 与 `classification.json` 位于该任务目录。预览转 PNG 不改变参与推理与哈希的上传原字节。
- 只有完整 GT 且成功模型存在才创建 `MetricSet(scope=classification_batch)`；成功/部分成功结果注册 `Artifact(kind=classification_result)`；关键操作写 AuditLog。

### 3.2 安全与既有能力边界

- 普通用户不能通过新接口上传 `.py` 或任意 `.pth`，只可选择六个明确白名单的本地可信内置模型。`weights=None` 构建六类网络；实际加载流再次核对 SHA，`weights_only=True`、`strict=True`、CPU、eval/inference_mode，不采用宽松加载。
- 本人批次才能提交；未提交导师的其他学生任务不可见。提交导师、撤回、重跑继续使用已有记录授权。执行前及发布前检查用户仍 active、模型仍可运行、来源/角色与协议合法。
- 分类只放行注册的原图和分类 JSON；不放行 log、私有 inputs.json、目录扫描、分割 mask/CAM/overlay/bundle。跨用户结果、原图、JSON 访问有回归覆盖。
- 分类模型从分割模型目录过滤，并拒绝进入分割性能测量、分割创建/Worker、科研助手工具；分类批次不能作为分割上传批次使用。
- 分割 demo 无精度、NEU-20 正式评测与 GT 下载边界、学生 Docker 执行不变。RAG 集合与检索规则、首页完整介绍和 UI token 未改动。
- 钢铁目标检测、PCB/光伏仍为空入口；没有开放分类公开演示、学生分类插件、分类助手、分类正式评测协议或自动路由。
