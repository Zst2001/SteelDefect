## 1. 项目整体需求（一句话）

**一套双面常驻 CPU 网站**：对外是课题组工业钢铁缺陷检测的展示门户（横向洽谈、基金申请）；对内是学生实验台（AutoDL 训完导入 `.py+.pth`，与内置 baseline 对照、评测）。**网站不做训练。**

展示面：免登录首页（综述，同事写）+ 公开演示（预备样例、限次、只出可视化）。  
实验台：须登录；学生由**导师开通**，**关闭公开注册**。

硬禁令（任何切片都不得破）：

- 无 `/train`，不调用 `train.py` / `train_multi.py`
- Web 进程不 `import` 学生 `.py`；学生检查/推理走 Docker
- 无 GT 不算精度；**公开演示即使有 GT 也不报 mIoU 等任何精度**
- 不把公开榜单 / 第三方仓库写成「本组成果」或「本次现场精度」
- 不改同事正在写的首页综述正文（`HomeView.vue` 及首页文案）
- 不另建第二套企业站；不做三档推荐、数据体检、基金报告（后置）
