## 2. 核心技术（本轮学术 RAG）

不要引入 LangChain / LlamaIndex / RAGFlow / CrewAI / LangGraph。实现全在本仓库服务里。

```text
用户问句
  → 追问改写 / 「第 N 条」复用（无 embed）
  → Redis 缓存 embedding（未命中则火山方舟 multimodal）
  → Milvus 集合 ippilab COSINE 检索 24 条
  → 专名放行 0.45–0.48 → 父块去重 → 按 (file_name, block_type) 错开 → 最多 5 条
  → 写作 LLM SSE 流式；未命中拒答，不编 DOI
```

| 层 | 技术 | 约束 |
|----|------|------|
| 向量库 | 远程 **Milvus 2.5.10**，集合名必须是 **`ippilab`** | 禁止读/写 `paper_literature` / `paper_literature_ug`；本仓库不 docker 向量库 |
| 向量化 | 火山方舟 `POST …/embeddings/multimodal`，模型 `doubao-embedding-vision-251215`，**1024 维** | 响应 `data` 是对象不是数组；维度不对抛 `EmbeddingError` |
| 检索 | `pymilvus.MilvusClient`，COSINE + AUTOINDEX，动态字段 | 分数是相似度（越大越好）；空结果 `via=milvus hit=false`，不回退关键词 |
| 降级 | 集合不可用 / 超时 → `via=local-fallback`，扫本站 `assistant_kb_docs` | UI：「本站审定条目（向量库不可用）」 |
| 切块 | `kb_chunks.py` 结构感知：`stage` / `paper_card` / `table_row` / `reference` / `narrative` | 父块不跨结构；子块文本前缀 `section_path` |
| 语料 | `docs/kb/*.md` + 五条 `SEED_DOCS` | 检测综述、分割综述、学习路线；不要把桌面原稿路径写进代码 |
| 写作 | 火山方舟 Chat Completions，模型 `deepseek-v4-1-flash-260910` | `thinking: {type: disabled}`；流式 SSE：`delta` / `done` / `error` |
| 会话 | MySQL `assistant_sessions` / `assistant_turns` | `working_json` 钉 `kb_query` / `kb_titles`；不是跨会话记忆 |
| 缓存 | Redis db1 JSON，key `kb:embed:{sha256}` | 只存 float 列表；失败穿透 |
| 前端 | Vue 3 + Vite，学术专科走 `/assistant` 流式接口 | 金相 token；来源条展示「实验室知识库」或降级文案 |

阈值（不要改除非重跑金标）：

- `SCORE_MIN = 0.48`，`SCORE_RESCUE = 0.45`，`SEARCH_LIMIT = 24`，`PARENT_LIMIT = 5`
- 专名正则：`10.\d{4,}/\S+|NEU-20|NEU-DET|ResNet|U-Net|YOLO`（大小写不敏感）
- 金标分界：域外最高约 0.431，域内最低约 0.540；0.35 会把番茄叶片放进来，已弃

重建索引（仅语料或 schema 变时）：

```powershell
.\.venv\Scripts\python.exe scripts\index_kb.py
```

只写 `ippilab`。上次成功：437 条，约 5 分钟（要打 embedding）。不要对另外两个集合跑任何脚本。
