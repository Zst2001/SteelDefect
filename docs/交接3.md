## 1. 项目在做什么

江西师范大学人工智能学院 · 智能感知与精密工业检测实验室（IPPI Lab）的双面网站：

- **展示面：** 免登录首页 + 限次公开演示。演示只用内置钢铁分割模型，出原图 / 掩码 / 叠加 / 拼图，**永不报精度**。
- **实验台：** 导师开通账号。学生把 AutoDL 上训完的权重复制回本地，导入后与内置 baseline 对照。有配对掩码才算本批 mIoU / mDice；正式评测只跑预置 NEU-20。
- **科研助手：** 登录后一块对话画布，专科选择器只有学术 / 分割 / 模型。学术检索走远程 Milvus 集合 `ippilab`。
- **正在扩展的产品目标：** 同一套站覆盖钢铁、PCB 板、太阳能电池板，每类场景将来都有检测、分类、分割。现在只把入口和拒绝提交的接口放好。

训练、续训、微调留在 AutoDL。网站只接收训好的文件。

## 5. 开发中遇到的问题，以及问题在哪

### 5.1 导航理解错了一次（已改，注意别改回去）

第一次实现把侧栏做成三个并列场景菜单：「钢铁」下面直接挂缺陷分割 / 正式评测 / 目标检测 / 缺陷分类，「PCB板」「太阳能电池板」各挂一条缺陷检测。

用户要的是：

- 侧栏只有一组「缺陷检测」，下面是 **钢铁检测、PCB板检测、太阳能电池板检测**
- 点进钢铁后，**主页面最上方**三个按钮切换缺陷分割、目标检测、缺陷分类
- PCB 和光伏先空着

正确实现就是 §3.2。不要再把任务名放回侧栏，也不要删掉钢铁页顶的三个按钮。

### 5.2 「审定的 CPU 权重」是什么

站点没有 GPU（需求书 R-05）。公开演示和内置对照必须在这台 CPU 上真实加载。

可以：AutoDL 训完，把 **权重字典**（键 `model_state` 或 `state_dict`）拷回本地。不要保存整个 CUDA 模型对象。

两条入口不要混：

- **实验台导入（钢铁分割现在就能用）：** 模型中心上传一个 `.py` + 一个 `.pth`。Docker 里 `load_state_dict(strict=True)` 并检查四维 logits。通过后只在本人实验台对照，不进公开演示，也不会打开 PCB 侧栏。
- **内嵌成内置模型：** 导师把结构和权重登记进内置表（现有钢铁分割权重在 `packages/infer/spec.py` 指向 `assets/baselines/neu/*.pth`）。新网络只把文件放进目录不会自动出现在侧栏。检测/分类权重即使拷回来，现有 runner 也会因形状不符判失败。

「审定」= 导师确认这份权重可以作为该场景的内置模型，并且本机 CPU 前向成功。只在 GPU 上能跑的，标成当前环境不可运行，不能进公开演示。

### 5.3 学术 RAG 不要再开

`kb_milvus.py` 只允许集合名 `ippilab`。同机还有 `paper_literature` / `paper_literature_ug`，禁止读写。BM25 做过方案、用户否了：集合已建，后加 function 要重建。阈值不要改，除非重跑金标。历史窗口的已知残留仍在 `llm_client.py`：`HISTORY_MAX=12`、`HISTORY_CHARS=8000`，从偏旧的轮先装，长对话可能丢掉更近的轮。没人要求时不要顺手重写。

### 5.4 文档口径容易看错

- 需求书文首仍写版本 3.2，修订表最后一行才是 **3.2.2**。导航以 §7.3 和代码为准。
- §17 末句仍写「无审定权重就开放 PCB / 光伏入口必须再升版」。这里的「开放」指**可提交、可报精度**。空入口已经按 3.2.1 / 3.2.2 合法存在，不要据此把空页删掉。
- §8.12.1 表格里钢铁一行仍写「保留现有钢铁分割实验台」，细于 §7.3。侧栏结构以 §7.3 和 `AppLayout.vue` 为准。
- 首页 catalog 可以按 classification / detection / segmentation 筛选文献卡片。那不是本站可运行任务。

### 5.5 其他坑

- Web / API 不 `import` 学生 `.py`。隔离检查失败应是不能启动，并带 `fail_stage`。
- 公开演示任务即使内部有 GT，也不写 MetricSet。`/metrics` 对 demo 为 404 `DEMO_NO_METRICS`。
- 助手不能分析 `type=demo`，不能把首页 catalog 当 `version_id`。
- 无 GT 的对比：`GET /api/tasks/{id}/metrics` 为 `{"available": false}`。
- 正式评测学生下载 NEU-20 GT 应 403 `GT_FORBIDDEN`。NEU-20 不是论文完整 test split。
- DeepLab / BiSeNet / DANet / PSPNet 构建 `pretrained=False`。
- 测试客户端有 Starlette / httpx 弃用警告，不影响 `test_scenes_empty.py` 通过。
- `ppt/` 是未跟踪的汇报材料，与网站无关。
