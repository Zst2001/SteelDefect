## 已拍板

1. **运行时：Harness**，不采用多 Agent 互调，也不采用「意图识别为主路由再进 Agent」。
2. **主路由：输入框旁的专科选择器**（学术 / 分割 / 模型）。不训练意图分类器。**禁止**一个输入框自动判断要检索、跑分割还是测参。换专科 = 开新会话线程，专科之间不互调、不串上下文。
3. **界面：豆包式对话。** 空画布居中问候；右上角「新对话」「对话列表」；会话栏在右侧，可展开/收起。未发消息不落库。同一会话可连续追问。不是三个互不相干的表单页。
4. **能力仍为 A0 + A1 + M + K。** 分割分析已有 compare/eval，可确认后封装快速对比；模型只调用实验室测参并对源码出建议文本；学术按审定语料检索，未命中拒答。
5. **测参是实验室能力**，助手只调用。FPS 文案锁死为本机换算。
6. **无 Key：证据 / 命中 / 测参档案仍开，写作关。** 对话壳不整页判死。
7. **学术：远程 Milvus 集合 `ippilab`（1024 维稠密）优先**，只含 `docs/kb` 与审定短条目。不可用时回退本站关键词。不读 `paper_literature`。本仓库不部署向量库。
8. **改 `.py` 只出文本，不写盘。** 落地仍走模型适配助手。
9. **正式名称：科研助手。** 专科名学术 / 分割 / 模型。工具 id 英文。

## 1. 要解决什么问题

学生 / 导师要在一个入口里**像聊天一样**把事情问清楚，而不是每问一次就重填表单：

- **分割：** 看懂已完成的对照或评测；追问弱类、协议、下一步；也可在对话里确认后封装快速对比。
- **学术：** 按审定语料问方向、学习路线、写作纪律；可以说「刚才那条再展开」。
- **模型：** 对着已选版本连续问建议，或查看 / 入队本机测参。

数字只来自工具 JSON。非目标不变：多 Agent、跨专科自动路由、在线训练、代写网络、顶刊全文、catalog 当 runnable、demo 当正式精度、助手写回 `model.py`。

---

## 2. 本站契约

1. 须登录。访客不可用。
2. Web 进程不 `import` 学生 `.py`。
3. 无 GT 不得口述精度。公开演示不得分析、不得代跑。
4. 不改变 `ModelVersion.status`。
5. 首页 catalog 不可当 `version_id`。
6. 代跑只封装 uploads + `create_compare_task`。禁止 demo / 新建正式评测。
7. 证据分级：测量事实 / 规则判断 / LLM 推测 / 未知。指标与 FPS 只许来自工具 JSON。
8. 测速不得为刷速度改分辨率。
9. 无密钥：写作关，工具结果仍进气泡。
10. 金相 UI token，不另起浅色或玻璃拟态皮肤。
11. **追问必须带本会话上下文。** 写作请求附带最近若干轮用户 / 助手文本，以及本会话钉住的工具结果（任务证据包 / 检索命中 / 测参档案 / 版本 id）。不得把追问当成全新的一问一答、丢掉上一轮任务。
12. 会话只属于创建者。换专科不得复用同一线程。

|------|----------|----------------------|

| 访客 | 不可见 | 不可见 |

## 4. 架构

```text
侧栏「科研助手」
    → 中：对话画布（空态问候 / 气泡）
    → 右上：新对话、对话列表（展开右侧会话栏）
    → 底：圆角输入舱（专科选择器 + 附件槽 + 输入）
    → harness：本会话 specialty 工具白名单、确认、审计
    → 工具 JSON
    → 写作：system prompt（按专科）+ 本会话历史 + 当前问题 + 钉住的证据
```

- 不引入 CrewAI / AutoGen / LangGraph。
- 入队类工具：气泡里先出将执行参数，用户点确认后再 RQ。
- 每轮工具最多 3 次。副作用工具未确认不得执行。
- 历史窗口：最近 **12** 条消息，合计大约 **8000** 字截断；工具 JSON 另附，不靠模型回忆数字。
- 钉住（working set）：分割钉 `task_id`；模型钉 `version_id`；学术可钉最近一次命中列表，供「展开第三条」类追问。用户换任务 / 换版本则更新钉子。

本会话内补槽（不是跨专科意图模型）：

1. 选择器给出专科。
2. 附件槽或已钉住的 id。
3. 用户自然语言作为当前问题。槽位不足则助手在气泡里追问，不猜 `task_id` / `version_id`。

## 5. 信息架构

侧栏仍只有一项「科研助手」→ `/assistant`。

页内**不再以三个表单 Tab 为主路径**。

| 区域 | 行为 |
|------|------|
| 右上角 | 「新对话」清空画布、不请求接口；「对话列表」展开/收起右侧栏 |
| 右侧栏 | 默认可收起。列出**已有消息**的本人会话；点选切换线程 |
| 选择器 | `academic` 学术 / `segment` 分割 / `model` 模型。空画布只改本地专科；已有气泡时换专科则离开当前线程，**第一条新消息**才落库 |
| 气泡 | 用户文本；助手文本；工具卡片（证据包、命中原文、测参、确认代跑） |
| 底栏附件 | 分割：选已有任务、上传原图/掩码、选 baseline；模型：选版本、可选「测参」；学术：无必填附件 |
| 外链 | 仍可去 `/models/perf`、对比/评测任务页、结果记录「用科研助手分析」 |

检测 / 分类：占位页，不得落到本画布工具。

从对比 / 评测 / 结果记录带 `taskId` 进入：打开或新建**分割**会话，钉住该任务，发出首轮分析，之后可追问。

## 7. 分割专科

钉住一条可分析任务后，用户每句都是对该证据包的追问，**不得要求重新点「分析本次结果」才带上下文**。

分析规则、证据包字段、demo 拒绝、无 GT 不得谈精度：与 v0.3 / 需求书 §8.9.1 相同。

代跑：在对话附件里上传并选模型，气泡确认后再入队；完成后可把新任务钉住再分析。禁止 demo / 正式评测 / catalog。

---

## 8. 学术专科

检索与拒答纪律同 v0.3 / §8.9.4。

追问：「刚才那条再展开」可使用本会话钉住的命中列表，不必假装没检索过。若追问明显换题，则重新检索；仍未命中则拒答，不得用闲聊补知识。

本专科不能调度 `infer.run` / `perf.measure` / `code.advise`。

---

## 9. 模型专科

`perf.measure` / `code.advise` 纪律同 v0.3 / §8.9.3。

钉住版本后，后续句子默认是对该版本的建议或对已读测参档案的追问。未钉版本时先在气泡里请用户从附件槽选择。内置模型不提供改源码；测参仍走实验室接口。

FPS 锁死文案：

> 本机 CPU、batch=1、dummy 随机输入的前向。FPS = 1000 / ms/图。不是 CUDA 论文测速，也不是测试集指标。

## 12. 数据与接口

**表**

- `assistant_sessions`：id、user_id、specialty、title、working_json（钉住的 task_id / version_id / 最近命中摘要）、created_at、updated_at
- `assistant_turns`：session_id、role（`user` / `assistant`）、content（用户原文）、tool_name、writing、evidence_json、task_id、llm_status、llm_model、…
- `assistant_kb_docs`：审定条目，学生只读

**API**

- `GET /api/assistant/tasks`
- `GET /api/assistant/sessions`：本人会话列表（可按 specialty 过滤）
- `POST /api/assistant/sessions`
- `GET /api/assistant/sessions/{id}`：含按时间排序的气泡
- `POST /api/assistant/sessions/{id}/messages`：用户一句话；服务端写入 user 回合，按专科调工具，再写入 assistant 回合（带历史写作）
- `POST /api/assistant/sessions/{id}/messages/stream`：同上，SSE 逐 token 推送写作（`delta` / `done`）；确认入队与代跑仍走 JSON
- `POST /api/assistant/sessions/{id}/turns`：仍可用于明确点名工具（确认入队、测参）；须落在本会话专科白名单

权限：仅创建者。访客 401。

写作：`llm_client.iter_chat_completion` 对流式画布，`chat_completion` 仍给适配助手；助手 prompt 禁止复用适配助手「修改点」词。

## 15. 验收

v0.3 的 AI-01～AI-12、AI-04～06、KB-01/02、M-01 仍有效。

对话化新增：

- **CH-01** 同一分割会话内第二次提问仍针对已钉住任务的证据包，写作请求含上一轮用户/助手文本。  
- **CH-02** 学术追问若仍命中，回答可引用本会话已出现的来源标题；换题未命中则拒答。  
- **CH-03** 右侧对话列表可展开/收起并切换本人已有会话；空会话不出现在列表。  
- **CH-04** 选择器从学术改到分割：未发消息不建会话；已有气泡则下一条走新线程。学术会话调 `infer.run` 仍 400。  
- **CH-05** 页面是对话画布（会话列表 + 输入框），不是三个互不相干的表单 Tab 作为唯一主路径。

## 16. 成功标准（v0.4）

打开科研助手，看到对话而不是三张互不记忆的表单。选「分割」、钉住一条评测，问完再追问弱类，助手仍对着同一证据包并记得上一句。选「学术」可连续问本站纪律。选「模型」可对同一版本连续要建议或读测参。无 Key 时卡片仍在气泡里。公开演示进不来。不写盘。

---

## 17. 锁定说明

**为何仍不自动路由专科：** 三条专科权限不同。选择器由用户点明，避免「问文献却入队测速」。

**为何必须带历史：** 表单一问一答无法满足「那一类再展开」「按刚才的口径改建议」。历史只用于本会话文本；数字仍以当轮工具 JSON 为准。

**为何换专科开新线程：** 避免检索语料与对比指标、本机 FPS 写进同一上下文。
