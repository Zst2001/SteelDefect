# 课题组工业缺陷分割科研平台需求分析书

文档状态：已冻结（对话确认版）  
版本：3.0  
日期：2026-09-18  
适用范围：同一套常驻网站的**对外展示门户**与**对内实验台**；本阶段只做需求分析，不编码、不选技术栈。首页综述正文由同事另行撰写，不纳入本文件的实现切片。

本文替代 v2.0 中下列结论：企业基金展示站后置为独立产品；网站以学生对照为唯一主路径；访客必须先登录。v1.0 / v2.0 已取消的在线训练、ZIP 包人工审核、独立论文出图工作台、模型审核员角色，本版继续取消。

## 1. 文档目的

把已确认的需求写成可评审、可验收的分析书，作为后续概要设计与编码的唯一功能事实源。未写入本文的能力，第一版不得自行扩展。

本文回答四件事：

1. 对外门户解决什么问题、对内实验台解决什么问题。
2. 访客 / 学生 / 导师各能做什么，第一版明确不做哪些。
3. 公开演示与快速对比如何分界（输入、限额、模型、指标）。
4. 学生模型如何接入实验台，以及网站与 AutoDL 训练如何分工。

---

## 2. 项目背景

课题组研究方向为计算机视觉，主线是工业表面缺陷检测；本课题聚焦钢铁缺陷语义分割。现有仓库已具备多数据集加载、多种分割模型、统一训练与评测脚本、部分可视化脚本、已训练权重，以及可运行的 Web 实验台（导入、对照、NEU-20 正式评测）。

导师现要求把**本站**做成可展示课题组工业钢铁缺陷检测方向的网站，用于后续承接工业横向和基金申请。因此产品主路径从「学生登录后对照」扩展为「外人可看、可点一次演示；学生登录后仍做实验」。

学生日常仍在 AutoDL 租用 GPU 训练。网站必须常驻，第一版不提供在线训练。论文插图由 Draw.io 完成；网站只给对齐协议后的分割对比图和可下载图层。

企业产线数据、合作方未授权图像**不得**进入实验台或公开样例库。本版不另建第二套企业网站；三档模型推荐、数据体检、基金报告导出仍后置。

## 3. 建设目标

### 3.1 一句话目标

建设常驻在线的课题组网站：**对外**以综述首页与限次公开演示展示钢铁缺陷分割能力，服务横向洽谈与基金申报的「可看、可点」；**对内**学生由导师开通账号后，将 AutoDL 训练产物导入，与内置 baseline 对照并做有标签评测。网站不做训练。

### 3.2 第一版成功标准

**展示面（访客，免登录）同时满足：**

1. 不注册即可打开首页与公开演示。
2. 只能点选平台预备样例（1–5 张），勾选 1–3 个内置模型（UNet / DeepLabV3+ / UNet++），得到原图 / 彩色掩码 / 叠加 / 拼图。
3. 同一 IP 加浏览器会话，每 24 小时最多 3 次演示任务；超限提示「明日再试或登录」。
4. 演示页不出现 mIoU、mDice、Acc 或任何精度数字（即使样例带 GT）。
5. 无公开自助注册。

**实验台（已登录学生 / 导师）同时满足：**

1. 内置 baseline 可对上传图片或预置数据做分割推理，并生成可视化。
2. 学生导入 `.py` + `.pth` 后，经自动检查即可加入对比；失败则明确提示不能启动。
3. 同一批图上，学生模型与 baseline 的分割可视化可拼接对比，并可下载。
4. 无 GT 时不算精度；有 GT 的快速对比给出本批参考指标；正式评测在固定测试集上给出全量指标。
5. 网站不依赖 AutoDL 开机即可访问账号、模型库、历史对比结果。

### 3.3 不作为第一版成功标准

- 在网站上启动训练或微调。
- 自动生成可直接投稿的论文图、图注、DPI/PDF 排版。
- 目标检测、图像分类真实跑通。
- 访客上传自有图片做演示。
- 首页综述正文、本组成果清单、合作意向表、英文页、基金报告。
- 知识库、顶刊检索上线（二期）。
- 三档模型推荐、企业数据体检、产线对接。

## 4. 需求决策冻结

| 编号 | 决策 | 说明 |
|------|------|------|
| R-01 | 一套双面，不是两套网站 | 对外门户与对内实验台共用同一部署。账号、任务仍按角色隔离。企业产线数据不进入本站。 |
| R-02 | 本版承担展示，不另建企业站 | 展示面 = 首页 + 公开演示 + 登录。三档推荐、基金报告、数据体检仍后置。 |
| R-03 | 第一版只承诺语义分割 | 检测、分类只保留并行占位页。访客可见菜单，未登录点击须登录；登录后仍不可提交真实任务。 |
| R-04 | 不做在线训练 | 训练、续训、微调仍在 AutoDL；网站只做展示演示、导入、推理、对比、评测。 |
| R-05 | 常驻 CPU 网站 | 网站不部署在 AutoDL 临时实例上。 |
| R-06 | 快速任务最多 50 张 | 仅约束登录后的快速对比上传。公开演示每次 1–5 张预备样例。正式评测用完整固定集，受配额而非 50 张限制。 |
| R-07 | 模型以 `.py` + `.pth` 导入 | 仅实验台。不接收任意 ZIP 直接运行。公开演示禁止学生模型。 |
| R-08 | 取消人工审核导入 | 无模型审核员；导师为最高管理员；导入后自动检查，失败即不能启动。学生**账号**由导师开通，不是自助注册。 |
| R-09 | 仍需隔离执行 | 学生 `.py` 不得在 Web 进程内直接 import。公开演示只跑审定的内置模型。 |
| R-10 | 对比拼图替代论文出图 | 网站生成可视化拼接；论文排版用 Draw.io。 |
| R-11 | 精度诚实 | 无 GT 不得生成或估计精度。公开演示即使有 GT 也不在访客页渲染任何精度。快速对比有 GT 时为参考指标，不代表完整测试集。正式评测写明当前固定集为 NEU-20，不是论文完整 test split。不得用 Acc 单独冒充分割效果。 |
| R-12 | LLM 只解释证据 | 不能证明代码安全、不能批准模型、不能替代人工看图。 |
| R-13 | 公开演示限次 | 未登录：IP + 浏览器会话，24 小时 3 次任务；每次 1–5 张预备样例；1–3 个内置模型。登录后走实验台配额，不适用这 3 次限额。 |
| R-14 | 关闭公开注册 | 访客不注册也能演示。学生账号由导师开通。登录页不提供自助注册。 |
| R-15 | 访客可见研究侧栏 | 访客能看到与登录用户相同的研究类菜单（不含系统管理）。无权限项点击后进入登录，登录成功后回到原目标页。 |
| R-16 | 首页内容权责分离 | 首页为综述体：钢铁缺陷检测的重要性、现有工作、我们的成果。本组成果清单本轮不强制上首页。综述正文由同事撰写；实现切片不得改写首页正文。领域公开工作与本组成果必须分开表述。 |

v2.0 的「两个网站完全独立 / 企业基金原型后置」由 R-01、R-02 取代，不得再按旧编号执行。

## 5. 用户与角色

### 5.1 访客（未登录）

- 打开首页、公开演示、登录页。
- 在公开演示中点选预备样例与 1–3 个内置模型，查看可视化，可下载本任务图层包。
- 受 R-13 限次；超限见「明日再试或登录」。
- 侧栏可见研究类菜单；点击工作台、快速对比、数据集、模型中心、正式评测、结果记录、科研助手、目标检测、缺陷分类时，进入登录（带回跳地址）。
- 不可上传图片、不可导入模型、不可发起正式评测、不可看到他人任务、不可下载固定测试集 GT、不可看见系统管理菜单。

### 5.2 学生（导师开通，登录后）

- 使用本人空间：工作台、快速对比、导入模型、正式评测、结果记录。
- 上传快速对比图片及可选 GT。
- 导入本人模型（`.py` + `.pth`）并查看自动检查结果。
- 选择 baseline，发起推理、对比、正式评测。
- 查看、下载、归档本人结果；可把实验分享给指定成员。
- 不受访客 3 次限额约束，受实验台配额约束（含快速对比 50 张）。
- 不能查看他人私有数据，不能修改固定测试集，不能管理用户和预置模型，不能自助注册第二个账号绕过导师开通。

### 5.3 导师（最高管理员）

- 拥有学生全部功能。
- **开通、启停学生账号**（替代公开注册）。
- 管理配额、预置数据集、内置 baseline、共享模型、演示预备样例范围。
- 下架异常模型、终止任务、查看审计日志。
- 管理固定测试集使用策略。
- 可将稳定学生模型设为课题组共享。

不设“模型审核员”。导师不逐份审批导入；系统自动检查通过即可被学生使用。共享到课题组范围由导师操作。

## 6. 总体方案（需求级，非实现选型）

```text
访客 / 学生 / 导师浏览器
    ↓
常驻网站（CPU 服务器）
    ├── 展示面（免登录）
    │     首页综述（同事维护）
    │     公开演示（预备样例 + 内置模型 + 限次）
    │     登录
    ├── 实验台（须登录）
    │     账号与权限（导师开通学生）
    │     数据集 / 模型库 / 对比 / 正式评测
    │     结果与下载
    ├── 二期：知识库、科研助手增强、论文检索
    └── 推理服务（优先 CPU 兼容的内置模型；学生模型隔离执行）

AutoDL GPU（学生自行开关）
    └── 仅用于线下训练；训练产物由学生导入实验台
```

原则：

- 网站长期在线；AutoDL 关闭不影响首页、演示（在限额内）、账号与历史对比。
- 第一版推理以 CPU 可运行的内置模型为主。公开演示**只**使用 UNet、DeepLabV3+、UNet++。
- 必须 CUDA 的模型第一版可标记为“当前环境不可运行”，不阻塞主流程，也不得进入公开演示。
- 学生不需要为本网站安装 Anaconda；运行环境由服务器统一提供。
- 展示面不得把公开论文代码或第三方数据集写成「本站可运行的本组成果」。

## 8. 功能需求

### 8.1 首页  F-HOME

- 公开，免登录。
- 定位：综述型门户，说明钢铁缺陷检测的重要性、领域现有工作、以及我们的成果。
- 本组成果清单本轮不作为首页必选模块；若正文提及成果，必须能区分「领域已有工作」与「本组成果」，禁止把第三方仓库/公开数据集暗示为本组已交付系统。
- **实现边界：** 综述文案与版式由同事改首页；本需求书不规定段落措辞。编码切片可为演示页预留入口，但不得覆盖同事的首页正文。
- 首页可链到公开演示；不要求在首页内嵌推理。

### 8.2 公开演示  F-DEMO（展示面核心）

与 F-CMP 分离。禁止把演示做成「免登录的快速对比」。

#### 输入

- 仅平台预备样例，来源为现有 NEU 钢表面图中固化的一组（每次任务用户点选 1–5 张）。
- 禁止访客上传、禁止粘贴外链图片、禁止改预备样例文件。
- 必须勾选 1–3 个内置模型，且只能是：UNet、DeepLabV3+、UNet++（当前环境可运行者）。不可选学生模型、不可选 CUDA-only 模型。
- 不提供 GT 上传；预备样例即便在存储中带掩码，演示协议视为「访客不可见 GT 指标」。

#### 限额

- 仅未登录访客：同一客户端用 IP 与浏览器会话共同识别，滚动 24 小时内最多 **3 次成功入队的演示任务**（失败因协议/限额被拒的不计入「成功入队」，但恶意刷提交须有基本防滥用）。
- 每次任务 1–5 张。
- 超限：阻断入队，文案为「明日再试或登录」，并提供登录入口。
- 已登录用户发起的同类内置模型样例跑，走实验台任务与配额，**不适用**上述 3 次限额。
- 不得靠清 Cookie 无限次：IP 限额仍生效。会话用于辅助识别，不能作为唯一钥匙。

#### 处理

- 同一批样例、同一预处理、同一颜色映射、同一输出对齐。
- 只跑勾选的内置模型；单模型失败可 partial_success，列出失败项。
- 预测掩码还原到便于对照的显示尺寸。
- **不计算、不落库、不返回** mIoU / mDice / Acc / 逐类 IoU 等精度字段（含 `metrics.available=false` 或等价：演示任务无 MetricSet）。
- 即便后台为对齐可视化读取了掩码，也不得在访客 API/页面出现精度数字。固定测试集 GT 仍禁止下载。

#### 展示

至少可切换：

```text
原图 | 内置模型 A | 内置模型 B | …
原图 | A 叠加     | B 叠加     | …
```

- 逐张翻页、类别图例、叠加透明度。
- 标明「公开演示 / 预备样例 / 不代表测试集性能」。
- 不渲染指标区、不渲染「参考指标」「正式评测指标」。

#### 下载

- 允许下载本任务图层包（拼图 + 单层 PNG + task.json），规则与实验台一致：无 PDF、无 metrics.json。
- 不提供他人演示任务的下载。

#### 登录回跳

- 从演示超限或侧栏进入登录，成功后回到原目标页（演示页或原实验台路径）。

### 8.3 工作台  F-DASH

须登录。

- 展示本人最近对比/评测任务、运行中与失败任务。
- 展示最近导入模型及自动检查状态。
- 提供入口：快速对比、导入模型、正式评测。
- 展示系统公告（维护、模型下架、测试集安排）。
- 不把公开演示的访客限次状态作为工作台主信息。

### 8.4 快速对比  F-CMP（实验台核心）

须登录。不得与 F-DEMO 混用上传通道与指标策略。

#### 输入

- 每任务 1–50 张 PNG / JPG / JPEG / 无损 TIFF。
- 可选一一对应的像素级 GT 掩码。
- 必须选择：1 个已通过检查的学生模型，或仅使用内置模型。
- 必须选择：1–3 个内置 baseline（第一版实际已有权重：UNet、DeepLabV3+、UNet++）。
- 提交前检查：类别数、输入通道、输入尺寸、预处理协议是否一致；不一致则阻止并说明原因。

#### 处理

- 同一批图、同一预处理、同一颜色映射、同一输出对齐方式。
- 各模型独立前向推理；一张失败不影响列出其他模型已成功结果。
- 预测掩码还原到便于对照的统一显示尺寸；保留原图下载。
- 无 GT：只生成可视化，不计算任何精度指标。
- 有 GT：计算该批样本的参考指标，并生成错误图。

#### 展示

无 GT 时至少提供两种视图，可切换：

```text
原图 | Baseline A | Baseline B | 学生模型
原图 | A 叠加     | B 叠加     | 学生叠加
```

有 GT 时增加：

```text
原图 | GT | Baseline A | Baseline B | 学生模型
原图 | GT | A 的 FP/FN | B 的 FP/FN | 学生的 FP/FN
```

交互：

- 逐张翻页、类别图例、叠加透明度。
- 多模型同步缩放，便于看边界。
- 标明样本量；有 GT 时标明「快速对比参考指标，不代表完整测试集性能」。
- 主表：mIoU、mDice、逐类 IoU。Acc 若计算，仅放详情，不作为主结论。

#### 下载（供 Draw.io 使用）

- 整组对比拼图 PNG。
- 各模型单独：彩色掩码、叠加图；有 GT 时含 GT 与错误图。
- 任务信息文本：模型名、权重哈希、预处理、是否有 GT。
- 不提供论文栏宽、DPI 档位、PDF/TIFF 出版导出、图注生成、自动挑选“最适合发论文”样本。图层包不含 metrics.json。

### 8.5 数据集中心  F-DATA

须登录。

- 预置数据集只读：与现有训练/评测入口实际支持的数据对齐（NEU 等，以代码加载器为准）。
- 学生可上传私有分割数据集（图片+掩码+类别定义+划分或授权平台按固定种子划分）。
- 正式数据集不受 50 张限制，受用户存储与样本配额限制。
- 自动校验：配对、可读性、尺寸、类别值、空掩码、损坏、完全重复、跨 split 重复（无法判断则标待确认；确认泄漏则禁止进入正式评测）。
- 展示分辨率、类别分布、缺陷面积、细小/细长比例、样例预览。
- 已被任务引用的数据版本不可原地修改；修正则出新版本。
- 固定测试集：学生可发起评测，不能下载 GT 或改 split。

### 8.6 模型中心  F-MODEL

须登录。访客点菜单须先登录，不得在未登录时列出学生私有模型。

#### 内置 baseline

- 由导师维护结构与已训练权重。
- 模型卡至少含：名称版本、任务类型（语义分割）、类别映射、输入尺寸、预处理、参数量、是否必须 CUDA、历史指标来源、可用可视化类型。
- 第一版优先上线 CPU 可运行、仓库中已有权重的分割模型。公开演示可用集合 = 其中的 UNet、DeepLabV3+、UNet++。
- 历史公开榜单指标若出现在模型卡，必须标明来源，不得写成「本站刚才这次推理的结果」。

#### 学生导入

学生上传：

- 一个模型源码 `.py`（第一版以单文件为主）。
- 对应 checkpoint `.pth`。
- 表单：模型名、版本、入口类/函数、`num_classes`、`in_channels`、输入尺寸、预处理、是否必须 CUDA、适用数据集说明。

自动检查（全部通过才进入“可运行”）：

1. 文件类型与大小限制；拒绝可执行文件与嵌套压缩包。
2. 隔离保存，计算源码与权重哈希。
3. 静态扫描危险调用（子进程、网络、任意文件遍历等），阻断项直接失败。
4. 隔离环境中 import 并 `build_model` / 实例化。
5. `load_state_dict(strict=True)`。
6. dummy 前向，检查输出为 `B×C×H×W` logits，C 与声明类别数一致。
7. 可选极小样本推理冒烟。

失败状态为“不能启动”，页面显示阶段、原因、建议，并提供日志下载（对学生脱敏路径）。不出现“等待导师审批”。

通过后默认仅本人可见；导师可设为课题组共享。下架后禁止新任务，历史任务只读保留版本信息。不可加入公开演示。

#### 接口约定（第一版）

- 入口返回 `torch.nn.Module`。
- `forward(image)` 主输出为未归一化分割 logits。
- 使用平台预处理与平台损失无关（网站不做训练）。
- 导入期不得访问网络、不得读训练数据、不得写任意路径。
- 不支持自定义训练循环、自定义数据加载器。
- 依赖仅允许平台白名单；缺依赖则检查失败。

### 8.7 正式评测  F-EVAL

须登录。

- 在固定数据版本与 split 上，对学生模型与若干 baseline 做公平评测。
- 第一版官方评测集仅为预置 **NEU-20**（`kind=preset` 且 `is_fixed_test`，全部有 GT）。无掩码或非固定测试集不能进入正式评测。
- 全员使用同一预处理与类别映射。
- 对全部样本计算指标；拼图按文件名排序抽取 8 张（可配置，默认 8）。
- 主展示：mIoU、mDice、逐类 IoU；Acc 仅详情。须声明：与训练脚本同一套 4 类 mIoU；**NEU-20 不是论文完整 test split**。
- 可记录参数量、权重大小、推理耗时及测试环境。Precision / Recall / F1 / 混淆矩阵若实现，不得替代主表三项，也不得在公开演示出现。
- 验证集结果与测试集结果分区，禁止混排。本版无独立验证集页面则不得把 NEU-20 写成验证集。
- 学生不可下载该固定集 GT。

### 8.8 结果记录  F-REC

须登录。第一版若页面仍为占位，验收不阻塞展示面；实验台任务元数据仍须落库。

每次任务保存：任务 ID、创建者（访客演示可为匿名会话标识）、图片或数据版本清单、模型与权重哈希、预处理、状态、日志、可视化、指标（仅实验台且有 GT 且非演示协议时）、下载包。

支持（实验台）：再跑同配置、备注、归档、分享给指定成员、打包下载。

删除受权限与保留策略约束；已分享或已引用任务的物理删除需导师确认或改为归档。访客演示任务不进入「分享给指定成员」。

### 8.9 科研助手  F-AI（第一版）

须登录。

- 只分析当前用户有权查看的对比/评测结构化结果。
- 内容：数据质量、哪类/哪种尺度较弱、边界差异、协议是否一致、无 GT 时说明无法谈精度、下一步仍应在 AutoDL 上做的实验建议。
- 证据分级：测量事实 / 规则判断 / LLM 推测 / 未知。
- 不编造指标，不执行或修改学生源码，不改变模型“可运行”状态。
- 不分析访客公开演示作为「正式精度结论」。

知识库 RAG、顶刊检索见第 10 节，不纳入第一版必做。

### 8.10 任务类型占位  F-TASK

- 语义分割：开放（展示面演示 + 实验台对照/评测）。
- 目标检测、缺陷分类：独立页面，说明规划中的数据格式与指标（检测为框 + mAP，分类为图级标签 + Accuracy/F1），按钮不可提交真实任务，不展示伪造指标。
- 访客可见这两项菜单，未登录须登录后才能看到占位说明。

### 8.11 系统管理  F-ADM

仅导师。菜单对访客与学生不可见。

- **开通 / 启停学生账号**，关闭公网自助注册入口。
- 用户配额、公告、存储与任务保留期。
- 预置数据、内置 baseline、公开演示预备样例的发布/下架。
- 失败任务终止、孤立文件清理、审计导出。
- 管理员操作留操作者、时间、对象、原因。

## 9. 可视化与指标规则

### 9.1 必须生成的可视化

公开演示与实验台推理均须：

- 原图
- 彩色预测掩码
- 原图+预测叠加
- 预测边界（第一版建议有，便于看轮廓）
- 多模型拼图

实验台有 GT 时增加：

- GT 彩色掩码
- TP/FP/FN 错误图

公开演示不要求向访客展示 GT 与错误图；若内部生成，也不得附带精度数字。

### 9.2 明确不生成

- 出版级 PDF/TIFF、固定栏宽、图注草稿、自动最优样本集
- 无 GT 时的精度数字或“估计准确率”
- 公开演示页上的任何精度数字
- 用生成式模型改画缺陷区域
- 将公开数据集指标或论文榜单写成本次现场推理的精度

### 9.3 指标（仅实验台）

现有评测脚本可提供 mIoU、mDice、Acc 及逐类 IoU/Dice/Acc。

- 快速对比有 GT：主展示 mIoU、mDice、逐类 IoU，并标注参考指标、本批 n、不代表完整测试集。
- 正式评测：同上为主展示，n 为固定集全量（NEU-20 为 20）；Acc 仅详情；disclaimer 必须含 NEU-20 ≠ 论文完整 test split。
- Precision/Recall/F1 与混淆矩阵若工期紧可作增强项，不得用 Acc 单独冒充分割效果。
- 效率只展示实际测到的参数量、文件大小、本次任务耗时；未测的 FLOPs/FPS 显示「未测量」，并注明环境。

## 14. 验收场景

**AC-01 内置模型快速推理（实验台）**  
登录后上传若干无 GT 图片，选择 1–2 个内置 baseline，得到原图/掩码/叠加/拼图，页面无 mIoU 等精度数字。

**AC-02 学生模型对比（实验台）**  
导入合法 `.py`+`.pth` 且检查通过后，与至少一个 baseline 在同一批图上拼接对比，可下载拼图与单模型图层。

**AC-03 导入失败可见（实验台）**  
缺入口、权重不匹配、输出通道错误、危险调用等分别显示“不能启动”及阶段原因，且不能加入对比。

**AC-04 有 GT 参考指标（实验台）**  
上传配对掩码后，显示该批 mIoU/mDice/逐类 IoU 与错误图，并标注小样本参考。

**AC-05 协议不一致阻断（实验台）**  
类别数或输入协议冲突的模型不能进入同一次对比。

**AC-06 隔离**  
用户不能通过改任务 ID 看到他人图片与结果。访客不能读取实验台私有任务。

**AC-07 无训练入口**  
界面不提供新建训练、续训、微调。

**AC-08 占位页**  
登录后检测、分类页可打开但不可提交任务，无伪造指标。未登录点击这两项须先登录。

**AC-09 常驻可用**  
无 GPU、无 AutoDL 时，仍可打开首页，并在限额内使用公开演示；登录后可查看历史对比（CUDA 模型新任务除外）。

**AC-10 公开演示免登录**  
未登录访问公开演示，点选 1–5 张预备样例与 1–3 个内置模型，得到可视化；页面与 metrics 接口均无精度数字。

**AC-11 演示限额**  
同一访客 24 小时内第 4 次入队被拒绝，文案含「明日再试或登录」。清 Cookie 后同一 IP 仍受限制。登录后的实验台任务不计这 3 次。

**AC-12 禁止访客上传与学生模型**  
公开演示无文件上传控件；请求学生模型或非预备样例须失败。

**AC-13 关闭公开注册**  
登录页无自助注册；注册 API 不可被访客成功创建学生账号。导师可开通学生账号后该学生能登录实验台。

**AC-14 访客菜单与回跳**  
未登录可见研究侧栏（不含系统管理）；点击快速对比进入登录，登录成功后到达原目标。系统管理对访客不可见。

**AC-15 正式评测诚实性（实验台）**  
NEU-20 评测 n=20，主表为 mIoU/mDice/逐类 IoU，disclaimer 声明非论文完整 test split；学生下载该集 GT 为 403。

**AC-16 首页权责**  
首页免登录可打开。本验收不检查综述学术内容是否完稿。实现不得把公开演示做成首页唯一内容而删除同事正在修改的综述结构。

## 16. 术语

| 术语 | 含义 |
|------|------|
| 展示面 | 免登录可使用的首页、公开演示、登录。 |
| 实验台 | 须登录的导入、快速对比、正式评测、工作台等内部能力。 |
| 访客 | 未登录使用者。 |
| 公开演示 | 预备样例 + 内置模型的限次可视化，不算精度。 |
| 语义分割 | 为每个像素预测类别；本站第一版唯一真实任务。 |
| 快速对比 | 登录后 ≤50 张图的学生模型 vs baseline 可视化拼接。 |
| 正式评测 | 固定测试集上的全量指标对比；第一版为 NEU-20。 |
| GT | 像素级真实掩码；模型预测不是 GT。 |
| 可运行模型 | 自动检查全部通过、未被下架的模型版本。 |
| 对比拼图 | 同一样本多模型可视化水平/网格拼接，供肉眼判断和 Draw.io 取用。 |
| 工业缺陷检测 | 产品总称；第一版实现为分割，不是检测框。 |
| 预备样例 | 平台固化的钢表面图，供公开演示点选，不是访客上传。 |
