# 课题组工业检测站需求分析书

文档状态：v3.2 已按 2026-10-16 对话确认升版。**v3.1.1 科研助手对话画布 + 专科选择器仍然有效**（学术 / 分割 / 模型；不增加检测、分类专科）。  
版本：3.2  
日期：2026-10-16  
适用范围：同一套常驻网站的**对外展示门户**与**对内实验台**。v3.0（2026-09-18）为展示面 + 实验台事实源；v3.1 / v3.1.1 只扩展科研助手。v3.2 把产品目标从「钢铁缺陷分割对照台」登记为**工业检测站**（钢铁 / PCB 板 / 太阳能电池板 × 检测 / 分类 / 分割）。2026-10-19 起，PCB 板与太阳能电池板的缺陷检测以空入口出现在侧栏，接口拒绝提交。没有审定 CPU 权重仍不跑推理、不报精度。当前可验收的真任务仍只有钢铁语义分割与现有公开演示。首页综述正文由同事另行撰写，不纳入实现切片。

本文替代 v2.0 中下列结论：企业基金展示站后置为独立产品；网站以学生对照为唯一主路径；访客必须先登录。v1.0 / v2.0 已取消的在线训练、ZIP 包人工审核、独立论文出图工作台、模型审核员角色，本版继续取消。

## 1. 文档目的

把已确认的需求写成可评审、可验收的分析书，作为后续概要设计与编码的唯一功能事实源。未写入本文的能力，第一版不得自行扩展。

本文回答四件事：

1. 对外门户解决什么问题、对内实验台解决什么问题。
2. 访客 / 学生 / 导师各能做什么，第一版明确不做哪些。
3. 公开演示与快速对比如何分界（输入、限额、模型、指标）。
4. 学生模型如何接入实验台，以及网站与 AutoDL 训练如何分工。

---

## 2. 项目背景

课题组研究方向为计算机视觉，主线是工业表面缺陷检测；本课题聚焦钢铁缺陷语义分割。现有仓库已具备多数据集加载、多种分割模型、统一训练与评测脚本、部分可视化脚本、已训练权重，以及可运行的 Web 实验台（导入、对照、NEU-20 正式评测）。

导师现要求把**本站**做成可展示课题组工业缺陷检测方向的网站，用于后续承接工业横向和基金申请。因此产品主路径从「学生登录后对照」扩展为「外人可看、可点一次演示；学生登录后仍做实验」。v3.2 进一步把目标登记为工业检测站：在钢铁分割之外，为 PCB 板与太阳能电池板预留检测、分类、分割。缺陷检测可以先露出空入口；没有审定 CPU 权重就不跑任务、不报精度。

学生日常仍在 AutoDL 租用 GPU 训练。网站必须常驻，第一版不提供在线训练。论文插图由 Draw.io 完成；网站只给对齐协议后的分割对比图和可下载图层。

企业产线数据、合作方未授权图像**不得**进入实验台或公开样例库。本版不另建第二套企业网站；三档模型推荐、数据体检、基金报告导出仍后置。

## 3. 建设目标

### 3.1 一句话目标

建设常驻在线的课题组**工业检测站**：**对外**以综述首页与限次公开演示展示能力，服务横向洽谈与基金申报的「可看、可点」；**对内**学生由导师开通账号后，将 AutoDL 训练产物导入，与内置 baseline 对照并做有标签评测。网站不做训练。

目标信息架构是侧栏三个场景（钢铁、PCB 板、太阳能电池板），每个场景内再分缺陷检测、缺陷分类、缺陷分割。三类任务各有插件契约与指标，不得混用。**在对应场景拿到审定 CPU 权重之前，可以露出空的缺陷检测入口，但页面不提交任务，接口返回拒绝，也不出现 mAP / F1 / mIoU。** 因此 v3.2 当前可验收的运行能力仍是：钢铁语义分割的公开演示与实验台。

### 3.2 第一版成功标准

**展示面（访客，免登录）同时满足：**

1. 不注册即可打开首页与公开演示。
2. 只能点选平台预备样例（1–5 张），勾选 1–3 个内置模型（UNet / DeepLabV3+ / UNet++），得到原图 / 彩色掩码 / 叠加 / 拼图。
3. 同一 IP 加浏览器会话，每 24 小时最多 3 次演示任务；超限提示「明日再试或登录」。
4. 演示页不出现 mIoU、mDice、Acc 或任何精度数字（即使样例带 GT）。
5. 无公开自助注册。

**实验台（已登录学生 / 导师）同时满足：**

1. 内置 baseline 可对上传图片或预置数据做分割推理，并生成可视化。
2. 学生导入 `.py` + `.pth` 后，经自动检查即可加入对比；失败则明确提示不能启动。
3. 同一批图上，学生模型与 baseline 的分割可视化可拼接对比，并可下载。
4. 无 GT 时不算精度；有 GT 的快速对比给出本批参考指标；正式评测在固定测试集上给出全量指标。
5. 网站不依赖 AutoDL 开机即可访问账号、模型库、历史对比结果。

### 3.3 不作为第一版成功标准

- 在网站上启动训练或微调。
- 自动生成可直接投稿的论文图、图注、DPI/PDF 排版。
- 在没有审定 CPU 权重时，把 PCB、光伏或钢铁检测/分类做成可提交任务，或写出 mAP / F1 / mIoU。
- 访客上传自有图片做演示。
- 首页综述正文、本组成果清单、合作意向表、英文页、基金报告。
- 顶刊全文检索、未审定外网论文（二期）。学术审定知识库见 §8.9.4。
- 三档模型推荐、企业数据体检、产线对接。

## 4. 需求决策冻结

| 编号 | 决策 | 说明 |
|------|------|------|
| R-01 | 一套双面，不是两套网站 | 对外门户与对内实验台共用同一部署。账号、任务仍按角色隔离。企业产线数据不进入本站。 |
| R-02 | 本版承担展示，不另建企业站 | 展示面 = 首页 + 公开演示 + 登录。三档推荐、基金报告、数据体检仍后置。 |
| R-03 | 场景导航，空入口不可提交 | v3.2 起取代 v3.1.1「第一版只承诺语义分割」。目标侧栏为三个场景，场景内再分检测 / 分类 / 分割（§7.3、§8.12）。PCB 板与太阳能电池板的缺陷检测可以出现在侧栏，页面与 `GET/POST /api/scenes/{scene}/detection` 标明空。无审定 CPU 权重时 POST 返回 409 `SCENE_EMPTY`，不入队、不报精度。分类与分割仍不建菜单。钢铁检测、分类占位页仍按 AC-08，不得改成可提交。 |
| R-04 | 不做在线训练 | 训练、续训、微调仍在 AutoDL；网站只做展示演示、导入、推理、对比、评测。 |
| R-05 | 常驻 CPU 网站 | 网站不部署在 AutoDL 临时实例上。 |
| R-06 | 快速任务最多 50 张 | 仅约束登录后的快速对比上传。公开演示每次 1–5 张预备样例。正式评测用完整固定集，受配额而非 50 张限制。 |
| R-07 | 模型以 `.py` + `.pth` 导入 | 仅实验台。不接收任意 ZIP 直接运行。公开演示禁止学生模型。 |
| R-08 | 取消人工审核导入 | 无模型审核员；导师为最高管理员；导入后自动检查，失败即不能启动。学生**账号**由导师开通，不是自助注册。 |
| R-09 | 仍需隔离执行 | 学生 `.py` 不得在 Web 进程内直接 import。公开演示只跑审定的内置模型。 |
| R-10 | 对比拼图替代论文出图 | 网站生成可视化拼接；论文排版用 Draw.io。 |
| R-11 | 精度诚实 | 无 GT 不得生成或估计精度。公开演示即使有 GT 也不在访客页渲染任何精度。快速对比有 GT 时为参考指标，不代表完整测试集。正式评测写明当前固定集为 NEU-20，不是论文完整 test split。不得用 Acc 单独冒充分割效果。 |
| R-12 | LLM 只解释证据 | 不能证明代码安全、不能批准模型、不能替代人工看图。 |
| R-13 | 公开演示限次 | 未登录：IP + 浏览器会话，24 小时 3 次任务；每次 1–5 张预备样例；1–3 个内置模型。登录后走实验台配额，不适用这 3 次限额。 |
| R-14 | 关闭公开注册 | 访客不注册也能演示。学生账号由导师开通。登录页不提供自助注册。 |
| R-15 | 访客可见研究侧栏 | 访客能看到与登录用户相同的研究类菜单（不含系统管理）。无权限项点击后进入登录，登录成功后回到原目标页。 |
| R-16 | 首页内容权责分离 | 首页为综述体：工业缺陷检测的重要性、现有工作、我们的成果。本组成果清单本轮不强制上首页。综述正文由同事撰写；实现切片不得改写首页正文，包括 hero 长文中的「实验室现未来将」。v3.2 不在首页增加 PCB / 光伏入口。领域公开工作与本组成果必须分开表述。 |
| R-17 | 三类插件契约分开 | 分割维持 `B×C×H×W` logits。检测输出框，分类输出图级 `B×K` logits。形状不符即不能启动。禁止用分割 argmax 冒充检测或分类。契约见 §8.12，本轮不改 runner。 |
| R-18 | 公开演示仍只钢铁分割 | 现网公开演示继续只跑 NEU-20 钢铁语义分割，永不报精度。PCB / 光伏不设公开演示，直到另一次升版且已有审定内置权重与预备样例。 |
| R-19 | 新场景数据与学术库隔离 | 不下载 DeepPCB、光伏 EL 等公开集，不把未审定 PCB / 光伏文献写入 Milvus `ippilab`。学术检索维持已收口的第一期，不重做 RAG，不上 BM25，不读写 `paper_literature`。 |
| R-20 | 助手不扩检测/分类专科 | 科研助手仍是一个 harness + 专科选择器（学术 / 分割 / 模型）。`infer.detect` / `infer.classify` 保持不可用。禁止跨专科自动路由，禁止 CrewAI / LangGraph。 |

v2.0 的「两个网站完全独立 / 企业基金原型后置」由 R-01、R-02 取代，不得再按旧编号执行。

## 5. 用户与角色

### 5.1 访客（未登录）

- 打开首页、公开演示、登录页。
- 在公开演示中点选预备样例与 1–3 个内置模型，查看可视化，可下载本任务图层包。
- 受 R-13 限次；超限见「明日再试或登录」。
- 侧栏可见研究类菜单；点击工作台、快速对比、数据集、模型中心、正式评测、结果记录、科研助手、目标检测、缺陷分类时，进入登录（带回跳地址）。
- 不可上传图片、不可导入模型、不可发起正式评测、不可看到他人任务、不可下载固定测试集 GT、不可看见系统管理菜单。

### 5.2 学生（导师开通，登录后）

- 使用本人空间：工作台、快速对比、导入模型、正式评测、结果记录。
- 上传快速对比图片及可选 GT。
- 导入本人模型（`.py` + `.pth`）并查看自动检查结果。
- 选择 baseline，发起推理、对比、正式评测。
- 查看、下载、归档本人结果；可把实验分享给指定成员。
- 不受访客 3 次限额约束，受实验台配额约束（含快速对比 50 张）。
- 不能查看他人私有数据，不能修改固定测试集，不能管理用户和预置模型，不能自助注册第二个账号绕过导师开通。

### 5.3 导师（最高管理员）

- 拥有学生全部功能。
- **开通、启停学生账号**（替代公开注册）。
- 管理配额、预置数据集、内置 baseline、共享模型、演示预备样例范围。
- 下架异常模型、终止任务、查看审计日志。
- 管理固定测试集使用策略。
- 可将稳定学生模型设为课题组共享。

不设“模型审核员”。导师不逐份审批导入；系统自动检查通过即可被学生使用。共享到课题组范围由导师操作。

## 6. 总体方案（需求级，非实现选型）

```text
访客 / 学生 / 导师浏览器
    ↓
常驻网站（CPU 服务器）
    ├── 展示面（免登录）
    │     首页综述（同事维护）
    │     公开演示（预备样例 + 内置模型 + 限次）
    │     登录
    ├── 实验台（须登录）
    │     账号与权限（导师开通学生）
    │     数据集 / 模型库 / 对比 / 正式评测
    │     结果与下载
    ├── 二期：知识库、科研助手增强、论文检索
    └── 推理服务（优先 CPU 兼容的内置模型；学生模型隔离执行）

AutoDL GPU（学生自行开关）
    └── 仅用于线下训练；训练产物由学生导入实验台
```

原则：

- 网站长期在线；AutoDL 关闭不影响首页、演示（在限额内）、账号与历史对比。
- 第一版推理以 CPU 可运行的内置模型为主。公开演示**只**使用 UNet、DeepLabV3+、UNet++。
- 必须 CUDA 的模型第一版可标记为“当前环境不可运行”，不阻塞主流程，也不得进入公开演示。
- 学生不需要为本网站安装 Anaconda；运行环境由服务器统一提供。
- 展示面不得把公开论文代码或第三方数据集写成「本站可运行的本组成果」。

## 7. 信息架构

### 7.1 导航（第一版）

访客与已登录用户看到同一组研究类菜单，顺序如下。系统管理仅导师登录后可见。

1. 首页（公开，综述；正文同事维护）
2. 公开演示（公开，本版新增）
3. 工作台（须登录）
4. 快速对比（须登录；实验台主功能）
5. 数据集（须登录）
6. 模型中心（须登录）
7. 正式评测（须登录）
8. 结果记录（须登录）
9. 科研助手（须登录；分割：分析已有对比/评测并可封装快速对比；模型：测参与源码建议文本；学术：审定知识库）
10. 目标检测（须登录后的规划占位）
11. 缺陷分类（须登录后的规划占位）
12. 系统管理（仅导师）

侧栏底部：未登录显示「访客」与「登录」；已登录显示身份与退出。不显示「注册」。

二期增加：顶刊全文检索。学术审定知识库见 §8.9.4。  
不设：训练任务、论文可视化、审核中心、自助注册。

上面 1–12 是 v3.1.1 的平铺菜单。当前侧栏在「缺陷检测」下只有三个场景：钢铁检测、PCB板检测、太阳能电池板检测。三个任务按钮只出现在钢铁页顶部，见 §7.3。

### 7.2 权限与跳转

| 页面 | 未登录 | 学生 | 导师 |
|------|--------|------|------|
| 首页 | 可浏览 | 可浏览 | 可浏览 |
| 公开演示 | 可跑（计访客限额） | 可进入；限额按实验台规则，不计 3 次访客额 | 同学生 |
| 登录 | 可打开 | 已登录则回到首页或原 redirect | 同学生 |
| 工作台及实验台其余页 | 跳转登录，成功后回原页 | 可用本人数据 | 可用并含管理 |
| 系统管理 | 菜单不可见 | 不可见 | 可见 |

检测 / 分类，以及 PCB 板、太阳能电池板缺陷检测：未登录点菜单 → 登录；登录后打开占位说明，按钮不可提交。

### 7.3 目标导航（v3.2）

侧栏「缺陷检测」下面只有三个场景，任务不直接挂在侧栏上。

1. 钢铁检测 → `/inspect/steel/segmentation`
   - 主页面顶部三个按钮：缺陷分割、目标检测、缺陷分类
   - 缺陷分割嵌入现有快速对照；页内链到正式评测 `/eval/new`
   - 目标检测、缺陷分类仍是占位，不可提交，不报精度
2. PCB板检测 → `/inspect/pcb`
   - 空页，不可提交。分类与分割不建按钮
3. 太阳能电池板检测 → `/inspect/solar`
   - 空页，不可提交。分类与分割不建按钮

`/compare/new`、`/detection`、`/classification`、`/pcb/detection`、`/solar/detection` 跳到上述地址。`/compare/:taskId` 与 `/eval/:taskId` 仍是结果页。

无审定 CPU 权重时，空入口不显示精度。`POST /api/scenes/pcb/detection/tasks` 与 solar 对应接口仍返回 409 `SCENE_EMPTY`。公开演示不扩展，仍只服从 R-18。

首页 hero 长文不改。不在首页加 PCB / 光伏入口。侧栏品牌字保持「对照台 / 工业缺陷分割」。

## 8. 功能需求

### 8.1 首页  F-HOME

- 公开，免登录。
- 定位：综述型门户，说明钢铁缺陷检测的重要性、领域现有工作、以及我们的成果。
- 本组成果清单本轮不作为首页必选模块；若正文提及成果，必须能区分「领域已有工作」与「本组成果」，禁止把第三方仓库/公开数据集暗示为本组已交付系统。

- 首页可链到公开演示；不要求在首页内嵌推理。

#### 8.12.1 场景

| 场景 id | 名称 | 侧栏 | 本版可运行 |
|---------|------|------|------------|
| `steel` | 钢铁表面 | 保留现有钢铁分割实验台与公开演示 | 仅语义分割 |
| `pcb` | PCB 板 | 缺陷检测空入口可见，不可提交 | 无 |

#### 8.12.2 共同导入入口

与现分割插件相同的装载方式仍然适用：单文件提供 `build_model(num_classes, in_channels=3, **kwargs)`，或表单指定的 `nn.Module` 类；另加权重 `.pth`。区别只在 `task_kind` 与 `forward` 主输出形状。一个文件不得同时充当分割网络和检测器。

#### 8.12.3 语义分割（已实现，保持不变）

- `forward` 主输出：`float` 张量，形状 `B×C×H×W`，`C = num_classes`，为像素 logits。
- 预测：对类别维 `argmax`。
- 标注：像素掩码。无掩码不算 mIoU / mDice。
- 实验台指标：有配对掩码时给出 mIoU、mDice、逐类 IoU。Acc 只在详情。正式评测的固定集仍是 NEU-20，不是论文完整 test split。
- 可视化：原图、彩色掩码、叠加、边界、多模型拼图。有 GT 时可有错误图。
- 公开演示：只出可视化，不写上述任何数字。

#### 8.12.4 目标检测（新契约，未实现）

`forward` 主输出是长度为 B 的列表，与 batch 一一对应，不是分割 logits。列表第 i 项是该张图的字典：

- `boxes`：`float32`，形状 `[N, 4]`，`xyxy`，坐标系为送入模型的那张图像素
- `scores`：`float32`，形状 `[N]`
- `labels`：`int64`，形状 `[N]`，取值 `0 .. num_classes-1`

`N = 0` 合法，表示该图没有框。B=1 时仍返回长度为 1 的列表，不直接返回单个字典。若主输出是四维 `B×C×H×W`，隔离检查失败，禁止对其 `argmax` 后当成检测框。

标注字段是框：`x1, y1, x2, y2, class_id`。文件用 JSON 还是文本，留到编码切片开工时再定，但不得用像素掩码充当框。无框标注不算 mAP。

实验台指标只使用 **mAP@0.5**。不计算 mIoU，不用分类 F1 代替 mAP。可视化是原图上的框，不是彩色掩码。公开演示即使将来开放，也不写 mAP。

#### 8.12.5 缺陷分类（新契约，未实现）

`forward` 主输出：`float32` 张量，形状 `B×K`，`K = num_classes`，为图级 logits。二维以外的输出（含四维分割图）隔离检查失败。

标注是每张图一个类别 id。实验台指标为 **Accuracy** 与 **macro-F1**。无图级标签不算这两项，也不估计。可视化是预测类别名，不是掩码，不算 mIoU。公开演示不写 Accuracy / F1。

## 9. 可视化与指标规则

§9.1–§9.3 只约束**已经在跑的钢铁语义分割**。检测框与图级分类的可视化、指标以 §8.12.4、§8.12.5 为准，在对应任务可运行之前不生成。

### 9.1 必须生成的可视化

钢铁语义分割的公开演示与实验台推理均须：

- 原图
- 彩色预测掩码
- 原图+预测叠加
- 预测边界（第一版建议有，便于看轮廓）
- 多模型拼图

实验台有 GT 时增加：

- GT 彩色掩码
- TP/FP/FN 错误图

公开演示不要求向访客展示 GT 与错误图；若内部生成，也不得附带精度数字。

### 9.2 明确不生成

- 出版级 PDF/TIFF、固定栏宽、图注草稿、自动最优样本集
- 无 GT 时的精度数字或“估计准确率”
- 公开演示页上的任何精度数字
- 用生成式模型改画缺陷区域
- 将公开数据集指标或论文榜单写成本次现场推理的精度

### 9.3 指标（仅实验台）

现有评测脚本可提供 mIoU、mDice、Acc 及逐类 IoU/Dice/Acc。

- 快速对比有 GT：主展示 mIoU、mDice、逐类 IoU，并标注参考指标、本批 n、不代表完整测试集。
- 正式评测：同上为主展示，n 为固定集全量（NEU-20 为 20）；Acc 仅详情；disclaimer 必须含 NEU-20 ≠ 论文完整 test split。
- Precision/Recall/F1 与混淆矩阵若工期紧可作增强项，不得用 Acc 单独冒充分割效果。
- 效率只展示实际测到的参数量、文件大小、本次任务耗时；未测的 FLOPs/FPS 显示「未测量」，并注明环境。

- 无审定 CPU 权重时提交检测 / 分类 / PCB / 光伏任务，或在页面上填写精度

- 另建独立企业网站；三档推荐、数据体检、基金报告

## 14. 验收场景

**AC-01 内置模型快速推理（实验台）**  
登录后上传若干无 GT 图片，选择 1–2 个内置 baseline，得到原图/掩码/叠加/拼图，页面无 mIoU 等精度数字。

**AC-02 学生模型对比（实验台）**  
导入合法 `.py`+`.pth` 且检查通过后，与至少一个 baseline 在同一批图上拼接对比，可下载拼图与单模型图层。

**AC-03 导入失败可见（实验台）**  
缺入口、权重不匹配、输出通道错误、危险调用等分别显示“不能启动”及阶段原因，且不能加入对比。

**AC-04 有 GT 参考指标（实验台）**  
上传配对掩码后，显示该批 mIoU/mDice/逐类 IoU 与错误图，并标注小样本参考。

**AC-05 协议不一致阻断（实验台）**  
类别数或输入协议冲突的模型不能进入同一次对比。

**AC-06 隔离**  
用户不能通过改任务 ID 看到他人图片与结果。访客不能读取实验台私有任务。

**AC-07 无训练入口**  
界面不提供新建训练、续训、微调。

**AC-08 占位页**  
登录后钢铁检测、分类页可打开但不可提交任务，无伪造指标。未登录点击这两项须先登录。PCB 板与太阳能电池板的缺陷检测页同样可打开、按钮不可提交；未登录访问须先登录。对应 POST 为 409 `SCENE_EMPTY`，响应无精度字段。

**AC-09 常驻可用**  
无 GPU、无 AutoDL 时，仍可打开首页，并在限额内使用公开演示；登录后可查看历史对比（CUDA 模型新任务除外）。

**AC-10 公开演示免登录**  
未登录访问公开演示，点选 1–5 张预备样例与 1–3 个内置模型，得到可视化；页面与 metrics 接口均无精度数字。

**AC-11 演示限额**  
同一访客 24 小时内第 4 次入队被拒绝，文案含「明日再试或登录」。清 Cookie 后同一 IP 仍受限制。登录后的实验台任务不计这 3 次。

**AC-12 禁止访客上传与学生模型**  
公开演示无文件上传控件；请求学生模型或非预备样例须失败。

**AC-13 关闭公开注册**  
登录页无自助注册；注册 API 不可被访客成功创建学生账号。导师可开通学生账号后该学生能登录实验台。

**AC-14 访客菜单与回跳**  
未登录可见研究侧栏（不含系统管理）；点击快速对比进入登录，登录成功后到达原目标。系统管理对访客不可见。

**AC-15 正式评测诚实性（实验台）**  
NEU-20 评测 n=20，主表为 mIoU/mDice/逐类 IoU，disclaimer 声明非论文完整 test split；学生下载该集 GT 为 403。

**AC-16 首页权责**  
首页免登录可打开。本验收不检查综述学术内容是否完稿。实现不得把公开演示做成首页唯一内容而删除同事正在修改的综述结构。

## 16. 术语

| 术语 | 含义 |
|------|------|
| 展示面 | 免登录可使用的首页、公开演示、登录。 |
| 实验台 | 须登录的导入、快速对比、正式评测、工作台等内部能力。 |
| 访客 | 未登录使用者。 |
| 公开演示 | 预备样例 + 内置模型的限次可视化，不算精度。 |
| 场景 | 侧栏分组：钢铁、PCB 板、太阳能电池板。后两者目前只有空的缺陷检测入口。 |
| 语义分割 | 为每个像素预测类别。插件主输出 `B×C×H×W` logits。当前唯一可运行任务。 |
| 目标检测 | 为缺陷给出框。插件主输出 `boxes` / `scores` / `labels`，不是分割 logits。指标 mAP@0.5。尚未可运行。 |
| 缺陷分类 | 为整张图预测一个类别。插件主输出 `B×K` logits。指标 Accuracy 与 macro-F1。尚未可运行。 |
| 快速对比 | 登录后 ≤50 张图的学生模型 vs baseline 可视化拼接。当前只用于钢铁分割。 |
| 正式评测 | 固定测试集上的全量指标对比；当前为 NEU-20 钢铁分割。 |
| GT | 与任务种类对应的标注：分割是像素掩码，检测是框，分类是图级类别。模型预测不是 GT。 |
| 可运行模型 | 自动检查全部通过、未被下架，且 `task_kind` 与输出形状一致的模型版本。 |
| 对比拼图 | 同一样本多模型可视化水平/网格拼接，供肉眼判断和 Draw.io 取用。分割拼图不混入检测框或分类分数。 |
| 工业缺陷检测 | 产品总称，覆盖三场景与三任务。当前可运行实现仍是钢铁语义分割。 |
| 预备样例 | 平台固化的钢表面图，供公开演示点选，不是访客上传。PCB / 光伏本版没有预备样例。 |
