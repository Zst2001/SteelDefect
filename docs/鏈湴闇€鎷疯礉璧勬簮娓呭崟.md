# 本地网站仓库需要从本服务器拷贝的文件

目标目录示例：`F:\360MoveData\Users\40336\Desktop\Bofang\Steel_lab`  
原则：第一版只要 **CPU baseline 的结构 + 对应权重 + 少量样例 + 指标/预处理代码**。不要拷整个 `/root/My`。

服务器上 **没有** `fast_scnn` 的 `.pth`。第三档请用已有的 `unetpp` 或 `bisenet` 代替选型文档里的 Fast-SCNN。

建议先只做 **NEU（4 类钢铁缺陷）** 这一套，对比协议简单。

---

## 1. 必拷：模型代码（小）

放到本地例如 `Steel_lab/third_party/compare/`：

| 服务器路径 | 用途 |
|------------|------|
| `/root/My/code/compare/unet.py` | UNet |
| `/root/My/code/compare/deeplabv3_plus.py` | DeepLabV3+（依赖 torchvision，无 ImageNet 预训练） |
| `/root/My/code/compare/unet_plus_plus.py` | UNet++，作为第三档速度/结构对照 |
| `/root/My/code/compare/bisenet.py` | 可选；依赖 `timm` |

**不要**整份拷贝 `compare/__init__.py`：它会 import Mamba、Mask2Former 等，网站装不上。在新仓库自己写一个只导出上述类的 `__init__.py`。

---

## 2. 必拷：推理/指标辅助代码（小）

放到本地例如 `Steel_lab/third_party/`：

| 服务器路径 | 用途 |
|------------|------|
| `/root/My/code/utils_losses_metrics.py` | mIoU / mDice / 混淆矩阵 |
| `/root/My/code/dataset_defects.py` | 与训练一致的 CLAHE、椒盐、resize；对照时必须同一套预处理 |
| `/root/My/code/eval.py` | **仅作参考**：从中抽取 `get_color_map`、`colorize_mask`、`build_model_from_checkpoint` 思路。文件很大且绑定训练脚本，不要当网站入口直接跑 |

不需要：`train_multi.py`、`train.py`、`Moegit/`、`visualize_moe_*.py`（第一版不出 Grad-CAM）。

---

## 3. 必拷：NEU 上已训好的 CPU 权重

放到本地例如 `Steel_lab/assets/baselines/neu/`：

| 服务器路径 | 约大小 | 网站角色 |
|------------|--------|----------|
| `/root/My/avisible/neu/best_unet.pth` | 66 MB | baseline 精度/通用 |
| `/root/My/avisible/neu/best_deeplabv3.pth` | 179 MB | baseline 较强 |
| `/root/My/avisible/neu/best_unetpp.pth` | 36 MB | 第三档（替代缺失的 Fast-SCNN） |

可选：

| `/root/My/avisible/neu/best_bisenet.pth` | 52 MB | 轻量档；代码依赖 timm |

合计大约 **280 MB**（不含 bisenet）。  
这些是 `avisible/neu/` 里用于论文对比的 best 权重，优先于 `code/models/neu/last_unet.pth`。

加载时注意：checkpoint 里一般是 `model_state` 字典，不是纯 `state_dict`。类别数 NEU=4。

完整 `data/NEU_Seg-main` 很大，网站第一版快速对比最多 50 张。建议只拷测试集 **8～20 对** 图+掩码，例如：

```text
/root/My/data/NEU_Seg-main/images/test/000001.jpg … 000020.jpg
/root/My/data/NEU_Seg-main/masks/test/000001.png … 000020.png
```

放到本地 `Steel_lab/assets/samples/neu/`。  
做「正式评测」再考虑拷完整 test split，仍不必拷 train。
